# 凯利公式（Kelly Criterion）

> **`f* = (bp − q) / b`** —— 在**可重复、乘法式结算**的世界里，把「胜率 p 与赔率 b」翻译成「这一把该押多少」。
> 它解决的不是「怎么赢」，而是「**怎么一直赢**」（讲稿行 71）。
> 一句话版本：**「你有多大 edge，就谈多大变现。」**（行 199）

## 要点

1. **出处**（行 49）：**约翰·凯利（John L. Kelly Jr., 1923–1965）**，贝尔实验室，**1956** 年论文
   *A New Interpretation of Information Rate*（*BSTJ* 35(4):917–926）—— 已核。
2. **它原本研究的是通信问题**（行 53–59）：设想赌徒通过**有噪声的私人电话线**接收赛马内幕，
   推出的最优下注比例，**其增益对应这条信道的信息传输率**。
3. **公式与一个算得出来的例子**（行 75–85）：`p = 0.6, b = 1` → **押 20%**（`(1×0.6 − 0.4)/1 = 0.2`）。
4. **赌场口诀**（行 89–97）：**`Kelly = Edge / Odds`** —— 分母是市场给的赔率，**分子 `edge = bp − q` 才是你的认知优势**。
5. **它对「不玩」也是明确的**（行 103）：「如果你不掌握大于零的 edge，凯利就要求你不要下注。
   说白了就是**你要是不比别人高明就别玩**。」
6. **它对「不敢玩」也是明确的**（行 115）：袁绍因幼子病重不出兵 → 官渡全军覆没，讲稿判为「**干大事而惜身**」，
   结论是「**如果 edge 好，出手是一种义务**」。
7. **三条底层指引**（行 135–145）：**别把自己清零** / **认知先行** / **追求复利**。
8. **收束**（行 207–209）：**「人生的根本自由是你始终有下一次下注的能力。」**
   「世界既不会奖励你的努力，也不会惩罚你的动机。**它只结算你的概率质量。**」

## 定义与背景

- **它要修的是「仓位问题」，不是「信息问题」**（行 37–43）：
  「为了几毛钱波动加杠杆杀进杀出，却在真正的赛道上犹豫不决」——
  「**押太大和不敢押都是错的。这不是信息问题，这是仓位问题。**」
- **适用域是讲稿自己划的**（行 69）：「在一个不确定的、**乘法式结算的**、可重复的世界里」。
  **离开这个前提，公式不适用。**

## 机制 / 原理

### 公式与两条注释（讲稿自带）

| 形式 | 出处 | 核查 |
|---|---|---|
| `f* = (bp − q) / b` | 行 75 | ✅ 计算正确 |
| `f* = p − q/b` | 注释 `[2]`，行 213 | ✅ 代数正确 |
| `edge = (p − P_m)/P_m`，`P_m = 1/(b+1)` | 注释 `[3]`，行 215 | ✅ **数学自洽（本页最硬的一条）** |

### 三条底层指引（行 135–145）

1. **别把自己清零**：贝叶斯主义者**不假设 p = 1**，还要留估计误差的余地。
2. **认知先行**：**「我们是把认知变现，不是用认知去解释变现。」**
3. **追求复利**：**「这是一个系统，而不是只赌一局。」**

### 一个跨学科的例证：表型赌注对冲（行 121–129）

沙门氏菌、枯草芽孢杆菌会让**一部分个体休眠** ——
**「进入休眠状态的细胞比例，在数学上等价于凯利公式中的未下注比例。」**
（细菌 bet-hedging 与 Kelly 最优下注比例的对应，**已被教材化讲授**，如 Caltech BE150。）

### 三个生活场景（行 155–193）

| 场景 | 讲稿的做法 |
|---|---|
| 职业规划 | **乘法资产** + **半凯利 / 分数凯利**试水 |
| 精力与健康 | 把日常活动**当作注** |
| **人际信任** | **小仓位试探 → 逐步加仓 → 永远保留止损**。行 187：「为什么不应该把银行密码告诉别人？因为**潜在收益非常小，潜在损失非常大**」 |

## 边界与反例

- **⚠️ 一处表述简化**（核查表 #4）：行 59 说「最优下注比例 f\* 在数学上**完全等同于**这条电话线的『信息传输率』」——
  凯利原文的结论是**最优对数增长率的增益**等于信道信息率（`ΔG* = I(X;Y)`）。
