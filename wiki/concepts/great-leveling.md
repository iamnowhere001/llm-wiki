# 大推平（Great Leveling）

> 20 世纪中叶，东亚三国不约而同地经历了一场社会**大推平**：世袭等级被铲掉，所有人站上同一条起跑线。
> **后果有两面** —— 机会平等是它的成就，「**跑道却只剩下一条**」是它的代价（[[2026-09-20-moloch]] 行 98–100）。

## 要点

1. **三国的三条路径**（行 96）：
   - **中国**：革命 —— 土改消灭地主，公私合营消化资本家；
   - **日本**：战败后财阀解体 + 农地改革；
   - **韩国**：亡国 —— 贵族在殖民时代就失去根基，随后朝鲜战争把残存的财富差距炸平。
2. **共同结果**（行 98）：「世袭等级被铲掉，所有人站上了同一条起跑线。」
3. **代价**（行 100–102）：「没有贵族，没有行会，没有庄园，没有什么可以传好几代的家产，那老百姓还能积累什么复利呢？**只有学历**。」
4. **它是 [[single-track-tournament]] 的第二个成因**（第一个是科举）—— 科举提供「价值单一」，大推平提供「机会平等」。
5. **欧洲的对照**（行 104）：旧社会的多元残余至今还在 —— 贵族、教会、行会、工匠传统。
6. **文献支撑**：Walter Scheidel, *The Great Leveler: Violence and the History of Inequality from the Stone Age to the Twenty-First Century*（Princeton UP, 2017）（本讲注 [9]）。

## 定义与背景

**大推平**指大规模、剧烈的**不平等压缩**。Scheidel 的中心论点是：历史上只有四件事能做到 —— 他称之为「四骑士」——
**大规模动员的战争、革命、国家崩溃、大规模瘟疫**；和平时期的政策改革**从未**造成过同等量级的压缩。

本讲把这套框架用在东亚三国：20 世纪中叶，三个社会各自经历了一次「推平」，且**路径不同**（革命 / 战败改革 / 亡国与战争）。

## 机制 / 原理

推平为什么**反而加剧内卷**？讲稿的论证是一条三段论：

```
① 推平 → 身份壁垒消失（机会平等）
② 同时 → 可继承的多元资产消失（土地 / 行会 / 贵族身份）
③ 而赛道只有一条 → 能积累的复利只剩学历
────────────────────────────────
∴ 价值单一 + 机会平等 = 全民锦标赛（行 106）
```

关键在于②：**推平拿走的不只是壁垒，也拿走了退路**。
当社会只有一条公认的成功路径时，**起点越平等，竞争越充分，内卷越剧烈**。
这正是讲稿那句反直觉结论的机制：「**卷，不是因为社会不公平；卷恰恰是『公平』的产物**」（行 108）。

## 边界与反例

- **⚠️ Scheidel 的书有学术争议** —— 「四骑士」框架被批评为**过度决定论**（把复杂的不平等史压缩成四个暴力机制）。本讲把它当作给定事实使用，未提争议。
- **⚠️ 本讲的使用范围未核** —— 书的主题是**全球通史**，本讲用它支撑「东亚三国各自的推平路径」。方向吻合，但**三国章节未逐页核**（见 [[2026-09-20-moloch]] 核查表 #9）。
- **推平不等于机会平等的全部来源**。教育扩张、劳动力市场结构都在起作用；本讲的因果链是**讲者的宏观判断**，不是文献结论。
- **不要把「大推平」与「科举」混为一谈** —— 前者是 20 世纪的一次性事件，后者是一千三百年的制度。它们是[[single-track-tournament]] 的**两个独立成因**。

## 与其他页面的关系

- 与 [[single-track-tournament]] 是**因果对**：科举提供价值单一（管道），大推平提供机会平等（参赛者）。
- 与 [[credential-inflation]] 相连：推平之后学历成了唯一可代际积累的资产，这正是它被超发的原因。
- 与 [[moloch]] 的关系是**间接的**：推平不制造摩洛克，它制造的是「**所有人都必须参赛**」这个前提。
- 指向 [[symbolic-capital]]：可继承的资产被铲除，唯有**制度化的文化资本**（文凭）能跨代传递。
- 指向 [[state-formation]]：推平往往由国家主导（土改、财阀解体、农地改革），是国家能力的一种极端行使。
- 与 [[value-pluralism]] 是**对位**：欧洲的多元残余 = 没被推平 = 不卷；东亚的推平 = 一条跑道 = 卷。
