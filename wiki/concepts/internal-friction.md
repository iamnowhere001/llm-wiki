# 内耗：三种定义与一个学术近邻

> 「内耗」是本项目最核心的待定义概念 —— 三份素材都用了它，**但给出了三种不同的定义**。这不是可以合并的差异，而是三种不同的病因学。
> 第四份素材（[[2026-09-18-cognitive-decoupling]]）没有给定义，但提供了它**最接近的学术概念**：反刍。

## 要点

- **素材一（金句层）**：内耗是「大脑系统在缺乏外部有效行动时，对内持续高频率『自我对话』的病理性激活」—— 处方是**行动**。
- **素材一（王路层）**：内耗「不是想得太多，而是感受得太少」，是用认知活动占据注意力，好把原始的身体感受压下去 —— 处方是**回到身体**。
- **素材二（YJango）**：内耗是「对未来的焦虑」与「对过去的懊悔」使人犹豫不决、无法专注 —— 处方是**接受混沌、放弃追求正确人生**。
- **素材四（认知解耦）**：不给定义，但给出**学术近邻** —— 反刍（rumination），处方是**拉开与想法的距离**。见 [[rumination]]。
- 四者**不互相矛盾，但处方方向不同**：一个要你多做，一个要你少想，一个要你别追求做对，一个要你退出想法。
- 所有素材都同意的一件事：**内耗不是懒惰或意志力问题**。

## 定义与背景

「内耗」在中文语境中是一个近十年流行起来的通俗词，三份素材都没有给它学术定义，而是各自从自己的框架出发描述它。**本库不合并它们**，理由见下。

### 定义 A：缺乏行动时的病理性自我对话

素材一开篇的金句条目（编号 16）给出：

> 内耗就是大脑系统在缺乏外部有效行动时，对内持续高频率「自我对话」的病理性激活。避免毒性自我对话，避免反刍。

这个定义的两个关键词是**「缺乏外部有效行动」**（病因在行动侧）和**「反刍」**（症状是重复性思维）。它把内耗归因于**行动缺口**。

### 定义 B：焦虑与懊悔的双向夹击

YJango 给出的描述：

> 这种内耗已经不再是「事先准备」和「事后总结」，而是深深陷入「对未来的焦虑」和「对过去的懊悔」中，使人们犹豫不决、无法专注，严重影响「眼前的工作与生活」。

这个定义的独特之处在于它区分了**健康的内耗与病理的内耗**：事先准备和事后总结是**有用的**思维活动，而内耗是它们**越界**之后的形态。病因不在思维本身，而在**思维指向的时间**（过去与未来，而非当下）。

### 定义 C：用思考替代感受

王路给出的定义，也是三者中最反直觉的一个：

> 很多人以为，内耗是因为想得太多，解决方案是少想。其实，内耗不是想得太多，而是感受得太少；是在用想来替代感受。当他反复琢磨「我是不是不够好」「这件事到底值不值」的时候，他不是在思考问题，而是在用认知活动来占据注意力，好把原始的身体感受压下去。

这个定义直接**否定了定义 A 的表述**（「高频率自我对话」听起来就是「想得太多」）。王路主张：**思维活动是症状，不是病因**；真正的病因是被回避的身体感受。

### 一个学术近邻：反刍（rumination）

第四份素材（[[2026-09-18-cognitive-decoupling]]）**没有给「内耗」下定义** —— 它谈的是**反刍**：

> 心理学上这叫「反刍（rumination）」。就如同牛反复咀嚼胃里的草，你的大脑不受控制地反复回放那些痛苦片段。

**它不是第四种定义，而是本页此前缺失的那样东西：一个可测量的学术概念。** 本页原先在「边界与反例」里指出「内耗缺乏学术定义」，现在有了最接近的对照物 —— 见 [[rumination]]。

它的价值在于**把模糊的词换成了可操作的对象**：

| | 「内耗」（通俗词） | 反刍（rumination） |
|---|---|---|
| 内容 | 泛指一切消耗性的心理活动 | **明确界定：不受控制地反复回放痛苦片段** |
| 特征 | 边界模糊 | 两个可识别特征：**回放性**（内容是已发生的事）+ **不受控制** |
| 研究传统 | 无 | 有测量工具与研究谱系（Nolen-Hoeksema 的反应风格理论） |
| 生理代价 | 无具体描述 | 皮质醇长期偏高 → 炎症 → 心血管风险 |

**有了这个对照，「内耗」这个词的边界才开始清楚**：反刍只覆盖了内耗的**内容层**（反复想什么），不覆盖**功能层**（为什么要想）。定义 C 说的「用想来替代感受」正是功能层 —— **反刍是定义 C 的一种具体表现形式。**

## 机制 / 原理

三种定义对应三条不同的机制链：

| 定义 | 机制链 | 处方 |
|---|---|---|
| A（行动缺口） | 缺乏外部有效行动 → 能量转向内部 → 高频自我对话 → 反刍加固 → 行动力进一步下降 | 微行动、两分钟原则、专注过程而非结果 |
| B（时间错位） | 选择过载 + 加速社会 → 焦虑（未来）与懊悔（过去）→ 犹豫不决 → 无法专注当下 | 接受「人生是混沌系统」、停止追求「正确人生」 |
| C（感受回避） | 原始身体感受被压下去 → 用认知活动占据注意力 → 表面是「想太多」，实质是「不敢感受」 | 回到具体体验：呼吸、跑步、热水澡、拥抱 |
| **D（反刍）** | 痛苦片段未被消化 → 大脑不受控地反复回放 → 皮质醇持续偏高 → 行动力下降 → 更多回放 | **退出想法**：认知解离、第三人称自称、时间抽离、写下三个新解释 |

**A 与 C 的张力最值得注意。** A 说「你在想太多，去行动」；C 说「你不是在想太多，你是在用想逃避感受，先回到身体」。对一个正在内耗的人，A 的建议（去行动）可能变成**新的自我要求**（「我怎么连行动都做不到」），而 C 的建议（先感受）反而更容易执行。**但 C 的处方在重度内耗中可能失效** —— 如果一个人已经无法感受身体，让他「回到身体」可能同样是一句空话。

**C 与 D 的处方方向相反，这是新出现的一处张力。** C 说**回到身体感受**（向内、向下），D 说**拉开与想法的距离**（向外、向上）。两者并非不能共存（可以先解离、再回到身体），但**四份素材中没有任何一处把它们串联起来**。这是 [[emotion-awareness]] 缺口表里「认知路径 vs 身体路径」这一条的具体形态 —— 收录本文后，这条缺口从「抽象担忧」变成了「两个具体处方之间的空白」。

> [!success] 2026-09-18：这条空白已由本库立论填补
> 见 [[cognitive-vs-somatic-paths]]。该页的命题是：**两条路径不是并列的处方，而是同一件事的两个入口** ——
> 都是「让一个已经停止接收新信息的系统重新开始接收」。身体入口恢复**内感受信息**，认知入口恢复**外部事实与他者视角**。
>
> 它同时解释了本页下面那条「C 与 D 方向相反」为什么**不是矛盾**：两者恢复的是两个不同的信息源，所以一个向内取、一个向外取。
>

## 边界与反例

- **「内耗」仍然不是一个严格的心理学概念。** 它现在有了一个明确标注的学术近邻（[[rumination]]），但**两者不等同**：反刍只覆盖内容层（反复回放），不覆盖功能层（用想替代感受）。本库使用「内耗」一词时应当说明指的是哪一层。
- **反刍与反思不是一回事，而这条界线仍然没有来源。** 素材一的定义 A 用「避免反刍」作处方，但素材二的整个论证建立在**反思是有价值的**（校准对世界的理解）之上；[[rumination]] 页也把这条列为首要缺口。**四份素材没有一份给出这条分界线** —— 它现在升格为本项目的**首要未解问题**（缺了它，读者可能把一切自我审视都当成反刍而停止思考）。
- **定义 C 与素材自身的另一处矛盾。** 素材一在「情绪管理」一节主张「情绪困扰来自对事件的解释，而解释可以用批判性思维干预」—— 这是**强化认知活动**的处方。而定义 C 主张**减少认知活动、回到身体**。两者在同一份素材里并存，未被调和。见「待办 / 开放问题」。
- **「内耗」可能被当作逃避行动的标签。** 如果一个人把所有不适都命名为「内耗」，可能反而免除了具体行动的责任 —— 这与 [[victim-mentality]] 的机制同源。素材未处理这个风险。
