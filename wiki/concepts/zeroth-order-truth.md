# 零阶道理（Zeroth-Order Truth）

> **「一个道理可以百分之百正确，却只值得百分之一的权重。」**（讲稿行 52）
> 零阶道理 = **在给定目标、时间尺度和比较对象之下，足以决定结论方向和主要量级的最小因果模型**（行 84）。

> [!note] 本页的三层必须分开看（自写）
> ①**方法骨架是既有的** —— 微扰理论（perturbation theory）、零阶近似 / 一阶修正、主导平衡（dominant balance）都是物理学标准方法，素材**未署名具体学者**（属学科通识，无单一首创人）；
> ②**「零阶道理」这个名字是讲稿自创的** —— 素材自陈：「请允许我说一个我原创的说法，叫『零阶道理』」（行 40），态度正确；「权重 vs 真假」「翻盘检验」「有损压缩」也都是**讲稿自拟的通俗表述**；
> ③**「显眼性偏差」是素材 AI 加工段自造的标签**（AI 段行 249），不是既有术语 —— 既有术语只有 evaluability hypothesis，见 [[salience-vs-importance]]。
> **本页引用时不得把 ② 挂到任何既有理论名下，也不得把 ③ 当既有术语。**

## 要点

- 人**不容易被错误的道理欺骗，更常见的灾难是被正确而不重要的道理劫持**（行 48）。
- 零阶项决定方向与量级，高阶项只做微调；**「小量可以修正零阶项，但是没有资格取代零阶项」**（行 70）。
- 找零阶项的物理方法叫**主导平衡**（行 72）：先问哪几项占主导，其余暂时扔掉。
- **大局观 = 有损压缩**（行 98）：只保住方向、量级、机制三样，其余允许不精确。
- 核心心法「**先问权重，再问真假**」（行 158）—— 不重要的命题，真假都无所谓。
- **唯一不能当小量处理的是硬约束**（行 172）：一旦发生就是破产或人命的小概率风险，必须一票否决。

## 定义与背景

**精确定义**（行 84）拆成三个关键词：**方向 / 量级 / 最小**。
「最小」是这条定义里最容易被跳过的一半 —— 它不是说「最重要的道理」，而是说「**足以定结论**的最小模型」。
多出来的每一项都增加分析成本，却不改变结论。

**方法来源**是物理学的**微扰理论**（行 60）：面对求不出精确解的问题，先算一个粗糙但抓住主干的零阶近似，
再加一阶、二阶修正逐级提精度。讲稿用**历法**作例（行 64–66）：零阶「一年约 365 天」→ 一阶「四年一闰」→ 二阶「百年不闰、四百年又闰」，
**修正项可以无穷无尽地加下去，但推翻不了零阶那一条**。
「高观点」这个说法借自**克莱因 1908《高观点下的初等数学》**（行 38，素材已正确署名）。

## 机制

**① 为什么高阶项看起来更诱人。** 「显眼」天然吸引关注，而「重要」要先定目标、再做计算（行 104）——
评价难度与重要性是两套不同的量，但人脑默认用前者代替后者。机制细节见 [[salience-vs-importance]]。

**② 大局观的两条具体化。** 一是**反馈回路**：「大局观就是复杂系统里最关键的那一两条反馈回路」（行 92），
判据是**因果控制权**而不是尺度大小 —— 军用地图必画桥，因为桥拥有因果控制权（行 96）；
二是**有损压缩**（行 98），只保方向 / 量级 / 机制。
两者的共通点是：**「大局和细节的区别，不是宏大与微小，而是控制力与装饰性」**（行 94）。

**③ 权重由目标函数决定。** 「真正的大局是由目标函数决定的。衡量一个因素是零阶还是高阶，
应该看它对你的目标有多大因果控制权」（行 138）。同一件事对外贸从业者是零阶、对旁人是高阶 ——
**零阶 / 高阶不是事物的属性，是「事物 × 你的目标」的属性**。

**④ 三条心法。**
- **权重优先**（行 158）：先问权重，再问真假。这给 [[value-of-information]] 补上了认知层前提 —— VOI 管「值多少」，本讲管「值不值得判真假」。
- **翻盘检验**（行 168）：不问「还有什么没考虑」（永远考虑不完），问「**还有什么足以扭转我的结论**」。
- **硬约束一票否决**（行 172）：小概率致命风险不能当小量，物理说法是「微扰级数不一定收敛」—— 这是本框架**唯一的例外**。

## 边界与反例

- **宏观 ≠ 大局观。** 讲稿专设一节讽刺「胸怀天下」型（行 132–152）：宏观经济、国际局势「对绝大多数人来说是你人生方程里的高阶小量」（行 140），
  处置是「**宏大叙事应该跟自身决策放在不同的账本上**」（行 146）—— 这是 [[mental-accounting]] 在注意力分配上的直接应用。
- **「度」不能从框架里算出来。** 讲稿自己划了界：「哪个是现场的零阶道理，由你在现场决定；那个度只能根据具体情况具体分析」（行 200）。
  **本框架给不出权重的具体数值，只给出提问顺序。**
- **硬约束是本框架的破口。** 微扰级数不收敛时，整套「小量可忽略」的推理失效 —— 这是 [[hard-constraints]] 与本页的接口：
  本页给的是「**为什么硬约束不能被优化掉**」的物理说法（不可当小量），与该页现有的「四类硬约束 + 算账」互补。
- **弱引注与未取回的两处**：行 116「研究表明身高对婚姻幸福影响不大」无年份无机构（弱引注）；
  行 74《矛盾论》、行 76 邓小平 1992 南方谈话**本轮外核未取回来源**，标（未验证）。

## 与其他页面的关系

- 是 [[value-of-information]] 的**前置**：先判权重（本页），再判信息价值（该页）；本页还给 VOI 补了一个例外 —— 硬约束不能按小量算。
- 与 [[compression-as-intelligence]] 同源：该页的「有损压缩 / 可解压性」判据，本页是它在**决策**语境的实例（只保方向 / 量级 / 机制）。
- 与 [[feedback-loop]] 互补：该页讲机制，本页讲「**如何用它看大局**」。
- 与 [[cybernetic-learning]] 同构：「重不重要取决于目标」（行 56 / 156），与该页「没有目标，大脑不会标记什么重要」是同一条的决策版。
- 与 [[narrative-as-objective-function]] 相接：本页把「大局由目标函数决定」接到了该页的同一概念上，是第二处落点。
- 与 [[salience-vs-importance]] 分工：本页给**处方**（先问权重），该页给**病因**（为什么显眼的会被当成重要的）。
- 区别于 [[hard-constraints]]：两页都谈硬约束，但该页是「基本世界观」第 4 讲的四类硬约束，本页只用其「不可当小量」这一层，**同名不同源**。
