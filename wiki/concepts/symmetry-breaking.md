# 对称性破缺（Symmetry Breaking）

> **宇宙与人事都从「什么都可能」冷却成「只有一种可能且坚不可摧」，这个过程叫对称性破缺**（行 52）。
> 于是「**命运不过是冷却了的偶然**」（行 64），而「**可塑性不是权力的函数，而是温度的函数**」（行 120）。
> 讲稿据此给出一套「**在局面将冷未冷时出手**」的三条心法：**可塑性 / 序参量 / 可固化性**（行 150–166）。

## 要点

- **命名与意象**（行 52 / 54 / 56）：立铅笔 —— 方程四面八方完全等价，可它一旦倒下就只能倒向一个方向、再也回不来；「**方程是对称的，结果是破缺的**」。
- **宇宙的三次破缺**（行 70 / 72 / 76–86）：Guth 1981 暴胀把量子涨落冻结成底稿；电弱对称性破缺让粒子获得质量；正反物质不对称留下「十亿分之一」的普通物质。三次都发生在**大爆炸后第一秒之内**（行 86），收束为「**破缺是世界的生成机制**」（行 90）。
- **社会的高温态**（行 96）：社会像一块**刚出炉的玻璃**，柔软可塑；判据句在行 108 ——「**改变同一件事，趁热的时候不费吹灰之力，冷却了就像移动星系一样难**」。
- **四个「奠定时刻」**（行 126–132）：华盛顿两届惯例、盖茨保留 MS-DOS 授权权、CERN 1993 把 WWW 软件置于公共领域、乔布斯 1997 砍掉 70% 产品线。
- **路径依赖**（行 138）：局面一旦一边倒，正反馈会把它越锁越死 ——「越多人接受它，接受它的理由就越充分」。
- **三条心法**（行 152 / 158 / 166）：**可塑性**（热系统必须有不止一个未来活着）→ **序参量**（能把无数局部选择压成一个宏观方向的量）→ **可固化性**（确保你这一小步被系统记住）。收束为「**命名 → 样板 → 公开 → 固化**」（行 190）。

## 正文

### 既有术语 vs 讲稿自拟（这一条最容易被误记）

| 术语 | 归属 | 判 |
|---|---|---|
| 对称性破缺（symmetry breaking） | **物理学既有术语**；素材引 **Anderson 1972《多者异也》**（行 60） | 非自创，署名正确 |
| 电弱对称性破缺 / 暴胀 | 标准物理概念；**Guth 1981**（行 70 / 72） | 非自创 |
| **序参量（order parameter）** | **物理学既有术语**（相变 / 临界现象，Landau 一脉），素材用法正确（行 158） | **不是讲稿自创** |
| **可塑性（plasticity）** | **通用词**，讲稿拿它当心法名，**未挂任何具名来源**（行 152） | **弱引注**（非伪引注） |
| **可固化性（lock-in potential）** | **未检索到既有的同名物理量**（行 166） | **讲稿自拟 / 通俗化术语** |
| 「社会高温态 / 温度 / 热」这套隐喻 | 素材用它串起物理与人事，**未挂来源** | **讲稿自拟的类比**（本库判断） |

**关键判断**：素材并未把三条心法挂到某个学者名下，而是说**「出自『临界现象』的相关研究」**（行 150）——
这是一个**领域级归属，不是具名的个人归属**。因此它**不构成**「改写既有框架而误标为既有」（那一条的要件是「把自拟的说成某具名来源的」），
但 **「可固化性」不应被当作既有物理量引用**，「可塑性」应标明是通用词。

### 三条心法的机制

**可塑性**（行 152）：热系统必须有**不止一个未来活着**。「如果玻璃一直都是热的，你的动作就只是噪声」（行 146）——
真正的窗口是**「将冷未冷」**：可能性已开始收敛，却还没收敛到只剩一种。

**序参量**（行 158–162）：把无数局部选择**压缩成一个宏观方向**的那个量。磁铁看净磁化方向，行业看有多少人采用同一标准，圈子看有多少关键人物公开承认同一个名分。
两条技术路线竞争时，用「采用 A 的比例 − 采用 B 的比例」当序参量：差值近零则系统还没选边；差值持续偏一侧则破缺正在发生（行 162）。

**可固化性**（行 166–168）：**确保你这一小步能被系统记住**。小动作原本没用（稳定系统消化能力强），
但**临近破缺的系统，小事会反复回响不死** ——「一篇文章转了又转，一个小 demo 让全行业焦虑」说明系统正在寻找出口（行 168）。
操作序列即「命名 → 样板 → 公开 → 固化」（行 190）。
