# 叙事即目标函数

> **「叙事决定了你的目标函数。」**（素材行 183）
> 目标不是被发现的既定事实，是**被讲出来的**。换叙事 = 换目标函数。
>
> **本页 `low`**：这句话本身只有一句断言；真正让它有分量的是它接上了 [[cybernetic-learning]] 的链条 ——
> 而那个接缝是本库自己做的，素材没说破。

## 要点

- 素材原句：**「叙事决定了你的目标函数」**（行 183），出现在「一切叙事都是主观的」之后。
- 直接推论：**我们不是根据事实做决策，我们是通过叙事做决策**（行 167）。
- 反例自查：素材**同时承认**「你不能说事实不重要」—— 事实是对叙事的**硬约束**，
  但「很多时候，虚构的叙事更能促成行动」。
- **本库立论部分**（`low`）：换叙事 = 换目标函数 = 换误差信号的来源 = 换你学得进去的东西。
- 它在 [[emotion-awareness]] 缺口表里回答了一个悬了很久的问题 —— 见「与其他页面的关系」第 2 条。
- **同一命题的讲稿级表述**（[[2026-09-18-capability-seeking-theorem-notes]] 行 62 / 80）：
  「成为『器』的本质就是瞄准一个单独的目标优化……你就是这个目标的奴隶」／「君子不器就是你必须高于任何目标函数」。
  **这是本页第一次拿到另一份素材的正面印证，且是讲稿正文（非 AI 加工段）—— 但它仍是讲者断言、零外部引注，故 `low` 不变。**

## 定义与背景

素材的上下文（行 173–187）：

1. 每时每刻周围都有无数剧情在上演，你关注哪个**只是主观选择**；
2. 同一个事实可以选不同的叙事方向（半瓶水 / 业绩好但股价已高）；
3. 于是 —— **「叙事决定了你的目标函数」**；
4. 例子：老板用「为了将来一起赚大钱」的叙事画饼，
   你可以跳出来，**「心想我得尽快跳槽，我在这儿的目标函数是经验值」**。

**「目标函数」这个词是从优化理论借来的**：它指的是那个决定「什么叫更好」的量。
素材用在这里的意思很具体 —— **叙事的作用不是描述世界，而是设定什么叫「赢」**。
同一个处境（工资低、加班多）在两种叙事下对应两个不同的目标函数（长期分红 vs 积累经验值），
于是最优行动完全不同，而**事实一个字都没变**。

这不是相对主义：素材明确留了口子 ——「**你不能说事实不重要**」。
事实的作用被定义为**对叙事的硬约束**：它是你编故事时不能越过的边界，
但它不告诉你该编哪个故事。

## 机制 / 原理

**素材给了操作层的验证机制**（D 段第四步，行 352–357，AI 生成）：
叙事里必须潜伏**可验证的因果关系**，否则大脑这个「预测机器」不会相信它。
所以要**制造微小的因果闭环** —— 若新叙事是「我是一个终身学习者」，
那么「每天早起读 10 页书并写下心得」就是证据；**当事实与叙事吻合，大脑才确认「我果然是这样的人」**。

用控制论的话说：**叙事设定参考信号，小行动产生误差信号，误差信号反过来强化或修正叙事。**
这是一个闭环，不是一个一次性的宣告。

**与 [[prediction-error]] 的接口**：预测误差是「模型的更新」，而叙事是那个被更新的**模型本身**。
PE 层处理的是「这条预测错了」，叙事层处理的是「我到底在预测什么」。
**两者不在同一个层级** —— 素材没有做这个区分，本库在这里补上（`low`）。

## 与其他页面的关系

**1. 与 [[cybernetic-learning]] 的接缝（本库立论，`low`）。**
那条链条是 `目标 → 误差信号 → 过滤器 → 相关性 → 留存`，且有一句社会性推论：
**「一个被规训成『上学→找工作』的人，他的过滤器会自动屏蔽就业以外的赚钱机会，因为那不在目标里。」**
把本页接上去：

```
叙事 → 目标函数 → 误差信号 → 过滤器 → 相关性 → 留存
```

**「目标」不再是链条的起点，它本身有了上游。** 这条推论素材没有说破，是两条线拼出来的 ——
**所以它是本库立论，不是素材主张**，引用时须标明。

**2. 它回答了 [[emotion-awareness]] 缺口表里一条悬置的张力。**
那一条写的是：Dan Koe 说没有目标就没有误差信号；YJango 说执迷「正确的人生」本身就是妄念 ——
**目标到底是误差信号的来源，还是焦虑的来源？**

本页给的是**第三种答案**：**目标不是给定量，所以这个二选一问错了问题。**
目标来自叙事，而叙事可以换 —— 于是问题从「要不要设定目标」变成
**「你现在这个目标是从哪个叙事里来的」**。
同一条链条上，「换叙事」就是**换误差信号的来源**。

**注意这是候选答案，不是已验证答案** —— 它没有任何一手材料支撑，`low`。

**3. 是 [[narrative-power]] 的生效机制。**
叙事权之所以被认为有威力，正因为它改的是目标函数，而不只是改说法。

**4. 与 [[narrative-as-first-principle]] 的关系要注意分寸。**
世界观层那一页本库判为「隐喻而非物理主张」，但**这一页不依赖它成立** ——
「叙事决定目标函数」是一个关于人的主张，不需要「叙事是宇宙第一性原理」为前提。

**5. 与 [[2026-09-18-capability-seeking-theorem-notes]]（成长战略第 1 讲）同构 —— 本页的第一份正面印证（2026-09-18 新增）。**
那讲讲「器」：**行 62**「以我之见，成为『器』的本质就是瞄准一个单独的目标优化，而牺牲生活的其他维度。
因为你眼中只有这个目标函数，所以你就是这个目标的奴隶」；**行 80**「君子不器就是你必须高于任何目标函数」。

**两页合起来是一条完整主张**：目标函数可以被叙事替换（本页），而「不器」＝**不把自己锁死在任何一个上**（那页）。
那页还把同一个机理推到了「多个目标也不行」——行 72–74 明确否掉了「多设几个目标就算君子」，
落到**主动 / 被动的区分**（行 76）。

**分寸**：那页的落点是「增加选项」（[[cybernetic-learning]] 的可达状态），本页的落点是「换叙事」——
**两者都在说「目标不是给定量」，但一个讲换、一个讲增。**
**该条不改变本页 `confidence`** —— 那页同样是讲者断言、零外部引注，两页共用一个证据缺口。

## 边界与反例

- **素材只给了一句断言 + 一个例子。** 没有论证，没有来源。它在本库的分量几乎全部来自第 1 条接缝。
  **2026-09-18 补**：成长战略第 1 讲（[[2026-09-18-capability-seeking-theorem-notes]] 行 62 / 80）给了同一命题的讲稿级表述，
  但**它同样零外部引注** —— 两页的证据缺口是同一个。
- **反方（素材 F 段，行 646–650）**：这一主张滑向极端就是**唯意志论** ——
  假设「只要改变元叙事，就能改变命运」，忽略贫困、战乱、阶级固化这些**极其坚硬的现实**。
  F 段的结论很硬：**「叙事不能凭空创造现实，它必须受制于物质资源的约束」**，
  并警告过度强调叙事决定论会演变成**受害者有罪论**。
- **「目标函数」是个比喻，不是一个量。** 素材没有给任何可测量定义，
  所以本页无法像 [[information-bottleneck]] 那样谈「压缩率」。
