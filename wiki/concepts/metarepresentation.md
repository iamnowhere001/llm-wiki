# 元表征（Metarepresentation）

> **「对表征关系本身的表征。」**（讲稿，转述 Pylyshyn）
> 通俗动作：**给思想加上引号** —— 不是「这样想」，而是「我在这样想」，且可以一直加下去。

> [!note] 归属与层（自写）
> ①**既有认知科学术语** —— 讲稿说「可以追溯到加拿大认知科学家泽农·派利夏恩（Zenon Pylyshyn）1978 年的工作」
> （*"When is attribution of beliefs justified?"*, *BBS* 1(4):592–593）。**这是可接受的常见归属之一，但非 Pylyshyn 独占**
> （亦常并提 Dennett 1978、Leslie 1987）。术语属实、年份属实，**非误挂，只是归属非唯一**。
> ②**「开放式递归性（open-ended recursivity）」= 普鲁斯特（Joëlle Proust）的既有术语**，出处是 Proust 2007
> （*"Metacognition and metarepresentation"*, *Synthese* 159:271–295）—— **素材未给年份**，登记即可。
> ③**「递归楼层」（行动层→目标层→问题层→叙事层→身份层→价值层）是讲稿自拟的分层**，未挂既有理论；
> 「宇宙的第一性原理是叙事，自由的第一性原理是跳出叙事」 也是**讲稿自拟的贯通**。

## 关键要点

- 元表征比**元认知**更彻底：元认知是「思考你的思考」，元表征是**对表征关系本身的表征**。
- 通俗说法：**给思想加上引号** —— 从「这是对的」变成「我在用『这是对的』这个框架」。
- **开放式递归性**：一个表征可以被另一个表征包裹，更高的那个又可以继续成为下一层的对象。
- 讲稿的**递归楼层**：行动层 → 目标层 → 问题层 → 叙事层 → 身份层 → 价值层，一路追问「从解题走到换题，再走到换我」。
- 核心动作只有一个：**把正在充当「主体」的东西变成眼前的「客体」** ——
  「它站在你身后，它就统治你；它站到你面前，你就统治它」。
- 上限问题：递归不能无限向上 —— 讲稿用《庄子》「至人无己」与《金刚经》「应无所住」收。

## 定义与背景

**元表征**在认知科学里有两个常见语境：一是**读心 / 心智理论**（把「某人相信 P」这个关系本身当作可表征的对象），
二是**元认知的形式化**（把「我对 X 的表征是否准确」当作可监控的对象）。讲稿走的是后者，但把它推得更远：
不是监控一个判断对不对，而是**看见自己正在用哪个框架**。

讲稿的递进句说明了它与二阶意愿的分工：
「**二阶意愿能帮你控制欲望，可有时候拿住你的根本不是欲望，是你想问题用的那个框架。
高级的自主性不只要跳出欲望，更要跳出框架。**」

## 机制

**加引号这一步在做什么。** 引号把命题从**被使用**的状态变成**被观察**的对象。
「健身」的例子 给出六层：行动层（要不要去）→ 目标层（为什么要去）→ 问题层（这是不是真问题）
→ 叙事层（我是什么样的人）→ 身份层（这个身份从哪来）→ 价值层（我凭什么信这个价值）。

**为什么这能动人。** 因为每一层都是**上一层的前提**：你在行动层争输赢，是接受了目标层给的靶子；
你在目标层挑方法，是接受了问题层的题。**能改的层数决定了自由的大小。**

**与情绪机制同构。** 讲稿把这一串工具（认知解离 / 认知重评 / 身份叙事 / 框架效应 / 反刍 / 所罗门悖论 / 苏格拉底提问 / 顿悟）
归到同一个动作：「**当你被一种情绪劫持的时候，只要能叫出它的名字，它就从『你』变成了『你的东西』**」。

## 边界与反例

- **递归不能无限向上，讲稿自己承认。** 引《庄子·逍遥游》 后判：「只要还有一个『我』在跳，楼上就永远还有楼」。
  落点是《金刚经》「应无所住，而生其心」与「佛陀反对的不是你有念头，是你把念头当成了你」。
- **六层楼的划分是讲稿自拟的**，不是认知科学的标准分层 —— 引用时不要写成「研究表明有这六层」。
- **讲稿内部对「最高层」的处理是反讽性的**：换用「人脑是个多元政体」叙事后，承认「所谓最高层，不过是此刻恰好拿到审查权的那个念头」 ——
  **这与「楼层」隐喻本身是冲突的**，本库登记为素材内部的未裁决张力。
- **AI 类比的上限**：讲稿结尾彩蛋引 Tom Zahavy《LLMs Can't Jump》（ICML 2026 Position Paper），
  核心论点是 LLM 缺**溯因（abduction）**跳跃；讲稿自陈「我暂时不敢这么说」（态度克制）。

## 与其他页面的关系

- 与 [[second-order-volition]] 分工：该页在**欲望层**（谁执政），本页在**框架层**（用什么在想）—— 素材自己按这个顺序递进。
- 与 [[subject-object-shift]] / [[robert-kegan]] 相接：本页的「加引号」就是凯根那句「让曾经的主体，变成客体」 的机制版。
- 与 [[cognitive-reappraisal]] 相邻：重评改的是**对事件的意义**，元表征改的是**你正在用的表示本身**，后者是前者的上层。
- 与 [[meta-narrative]] / [[narrative-identity]] 相接：叙事层与身份层正是这两页的对象，本页给出**它们处在第几层**。
- 与 [[rumination]] 构成反例：反刍是**在同一层里反复跑**，元表征是**换层** —— 两者常被混淆。
- 与 [[free-energy-principle]] / [[prediction-error]] 相接：换层相当于改生成模型的更高层参数，本库未做形式化。
