# 伯克森悖论（Berkson's Paradox）

> **「两个原本可能完全不相关的变量，如果你非得把它们加在一起，设定一个总的门槛，
> 然后只看那些越过门槛的样本，你就会发现这两个变量显得负相关。」**（讲稿行 155）
> 收束句：**「相亲不是人口普查，招聘不是社会抽样，门槛会制造对立，筛子会伪造规律。」**（行 167）

## 要点

1. **一句话机制**（行 155）：**两独立变量被「一个总门槛」筛过之后，会显得负相关。**
2. **它不是相关性错觉，是样本截断**：变量之间**原本无关**，是**筛选动作**造出了关系。
3. **讲稿列的民间「负相关」清单**（行 145–151）：帅 = 渣 / 美女脾气差 / 业务强情商低 / 体育好文化差 ——
   **「难道说老天爷讲公平……其实这些统统都是错觉。」**（行 153）
4. **婚恋市场的算账演示**（行 157–161）：设「男性综合吸引力 = 颜值 + 人品」，越过门槛才有资格进入样本 ——
   于是**门槛内两项都高的人必定是少数**，剩下的自然「一项高、一项低」。
5. **同一机制解释招聘**（行 165）：公司招的是「业务 + 情商」超过一定门槛的人 ——
   **两项都强的是极少数，两项都弱的进不来**，剩下你容易看见的就必定一项强、一项弱。
6. **判据句**（行 167）：**「相亲不是人口普查，招聘不是社会抽样。」**

## 定义与背景

- **原始出处**：**Joseph Berkson (1946)**，"Limitations of the Application of Fourfold Table Analysis to Hospital Data"。
  他观察到的现象是：在医院病人样本里，**两种疾病会显得负相关**（如糖尿病与胆囊炎），
  **而在一般人群里两者无关** —— 因为**同时患两种病的人更可能住院**，进入样本。
- **它的规范名称与别名**：通行叫 **Berkson's paradox / Berkson's bias / collider bias /
  endogenous selection bias / Berkson's fallacy** ——
  在因果推断语境里，它说的是**对 collider 条件化**（conditioning on a collider）后，两个原本独立的变量出现关联。
- **它属于「选择偏差」四类中的第四类**（讲稿行 61 的自分类：自我选择 / 幸存者 / 分组选拔 / **门槛**），
  但**它的机制与其他三类都不同**：其他三类是「某些个体被移出样本」，
  本类是「**样本只在多个变量的联合门槛之上保留**」。

## 机制 / 原理

### 门槛如何伪造负相关（讲稿行 155–165）

| 要素 | 讲稿的表述 | 说明 |
|---|---|---|
| 前提 | 两变量**原本可能完全不相关** | 不是「世界真的如此」 |
| 操作 | 把它们**加在一起**，设一个**总门槛** | 如「综合吸引力 = 颜值 + 人品」 |
| 观察 | **只看越过门槛的样本** | 相亲对象池 / 招聘录用池 |
| 结果 | 两变量**显得负相关** | **筛选动作的副产品** |
| 原因 | 门槛内**两项都高的必定是少数** | 双高的被抢走 / 双低的进不来 |

### 与「幸存者偏差」的机制差别（本库辨析，素材未展开）

| | 幸存者偏差 | 伯克森悖论 |
|---|---|---|
| 被移出样本的 | **结果差的那批**（死掉、清盘、失败） | **任一维度不足的那批** |
| 变量数 | 单变量（结果本身） | **双变量（联合门槛）** |
| 产生的错觉 | 「成功 = 某方法有效」 | 「**两个优点互斥**」 |
| 纠法 | 问「谁没来」 | 问「**门槛在哪、被谁设的**」 |

**两者都是「选择偏差」，但一个扭曲的是「成功率」，一个扭曲的是「变量之间的关系」。** 不要混用。

## 边界与反例

- **⚠️ 一处归属不当（本模块第二例术语错配）**：讲稿行 141 把「**门槛偏差（Threshold Bias）**」
  当作伯克森悖论的等价别名。**核查结果**：
  **内容属实、例子准确**（糖尿病–胆囊炎正是 Berkson 的原始案例），
  **但「Threshold Bias」在文献里的既有用法是别的意思**（基因组学的 Beavis effect / winner's curse、医学测量阈值、宇宙学阈值偏置等），
  **本库未检索到「Threshold Bias = Berkson's Paradox」这一等价命名的规范来源**。
  **措辞已弱化（「也叫」），不构成伪引注**；但**出处的等价命名不可追溯**。
  **本页的处置：正文只用「伯克森悖论 / 门槛」这一层，不把「Threshold Bias」当规范别名传播。**
- **⚠️ 与 [[heavy-tailed-distribution]] 的机制不要混用**：名校效应（属「分组选拔」类）在重尾世界里
  是「才华分布被端部截断」的案例，但**本讲用「门槛 / 负相关」拆（双变量）**，
  而非用「极端值决定平均」拆（单变量尾）。**两页可互引，机制不可互换。**
- **⚠️ AI 段的定性**：行 435–475「门槛偏差：为什么你总感觉『优秀的人都有缺点』」——
  **零引注、无新增事实主张、方向未反转** → 判**操作化延伸**，不降级。**本页不引用其任何论断。**
- **本页不主张「门槛不存在」**：门槛（招聘标准、择偶标准）本身是必要的；
  **本页说的是「门槛内的样本不能用来推断变量之间的关系」** —— 这是**使用范围的限制**，不是对门槛的否定。
