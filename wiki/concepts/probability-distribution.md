# 概率分布：决策决的不是结果，而是一个分布

> **决策，决的不是单次结果，而是一个「概率分布」**（讲稿行 57）。
> 你真正能决定的不是结果，而是**放弃哪些东西** —— 「**决策其实是对平行宇宙进行剪枝。**」（行 89）

## 要点

1. **开场是一次讲者自己做的小型统计检验**（行 35–49）：赤马红羊劫 —— **34** 组里 **13** 组落在重大动荡期（**38%**），
   而随机抽取 34 组连续两年的比例「大约是 **37%**」。结论：**并不比随机采样更突出**。
   ⭐ **讲稿主动交代了 AI 参与**（行 39：「**我直接让 GPT 列举了**……」）—— **归属透明，是本库已记的正面样本类型**。
2. **它要纠正的是「结果偏误（Outcome Bias）」**（行 63）：**安妮·杜克**称之为「**结果论（Resulting）**」，
   她在《对赌》里说「**生活更像是扑克而不是国际象棋**」。
3. **决策的词源即「剪枝」**（行 79–95）：**Decision ← 拉丁语 *decidere*，意思是「切断」或「杀掉」**；
   行 95：「**决策是一个暴力行为。**」
4. **六个可逐项检查的决策参数**（行 103–113）：**均值 / 方差 / 上限下限 / 偏度 / 峰度 / 稳健性** ——
   **这是全课第一次把「概率分布」拆成清单。**
5. **下限优先**（行 131–137）：**「决策的首要指望就不是『必胜』，而是『可活』。」**
6. **系统优于目标**（行 141–147）：行 141「高手应该尽量不让自己频繁进入高方差赌局，而是多用
   **低波动可重复的过程**积累胜利，这就叫『**善战者无赫赫之功**』」；并引**斯科特·亚当斯**的「**系统**而非具体目标」。
7. **一句最实用的判据**（行 179）：**「很多时候决策看的不是最好有多好，而是最坏能有多坏。」**
8. **收束**（行 187）：**「高水平决策者就如同斯多葛主义的射箭手。」**

## 定义与背景

- **它把「决策」与「结果」切开**：行 57 的定义句 —— 决策的对象是**分布**，结果只是分布的一次抽样。
- **所以「结果好」不能证明「决策对」**：篮球最后时刻的运气判罚（行 59）是讲稿给的例子。

## 机制 / 原理

### 六个参数（行 103–113）—— 本页最可操作的部分

| 参数 | 问它什么 |
|---|---|
| **均值** | 平均会怎样 |
| **方差** | 波动有多大 |
| **上限 / 下限** | 最好与最坏分别到哪 |
| **偏度** | 是左尾还是右尾 |
| **峰度** | 极端值有多极端 |
| **稳健性** | 前提变了会不会塌 |

### 下限优先的四句引文（行 131–137）

| 谁 | 说了什么 |
|---|---|
| **孙子** | 「昔之善战者，**先为不可胜**，以待敌之可胜」 |
| **芒格** | 「我只想知道**我会死在哪里**」 |
| **塔勒布** | 「永远不要因为一条河『**平均**』只有四英尺深，就涉水而过」 |
| **索罗斯** | 「看对时赚了多少，**看错时亏了多少**」→ 落脚于「**不对称性**」 |

### 三道演练（行 153–175）

- **肿瘤治疗**（行 155–160）：选窄分布还是双峰分布，**取决于病人是 80 岁还是 20 岁**。
- **大厂螺丝钉 vs 创业公司多面手**（行 164–169）：前者是**左尾风险**，后者是**右尾机会**。
- **保险**（行 173–175）：**买的不是期望值，而是「承担不起」这一约束**。
