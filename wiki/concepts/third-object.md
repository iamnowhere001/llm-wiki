# 第三物（Third Object）· 并载「边界物（Boundary Object）」

> **「共同理解是奢侈品，共同对象才是日用品。」**
>
> **第三物 = 能被双方共同看见、共同操作，从而把「人对人」的直接僵局，
> 改造成「人围物」的共同局面的东西**。
> 核心命题是**合作不必先有共识** ——「**人类不是先有了共识才合作，而是先能够一起盯住同一个东西**」。
> 收尾判据句：「**文明不是没有冲突。很多时候，文明是给冲突一个球。**」

> [!note] 素材质量
> 单一素材：万维钢《现代思维工具》「模块五 参与者」084 讲（[[2026-09-20-third-thing]]，`raw/` 235 行，4 张图）。
> **讲稿段 100%、AI 加工段 0 行**；7 条引注**全部真实，卷期页码无一处错**。
> 一处例外是讲稿收尾的小诗：它**由 AI 代笔且未署名**（**【有偈为证】**）。
> 讲者另外**自己声明扩用了 `boundary object`** —— 这不是引注问题（见「定义与背景」）。

## 关键要点

1. **合作不必先有共识**：共同理解是奢侈品，共同对象才是日用品。
2. **判据是「人围物」**：把「人对人」的僵局换成「人围物」的共局就算 —— 它**包含**边界物，但两义不可混用。
3. **机制是注意力**：不先说服对方，而是让双方同时看向同一个东西 —— 发育学证据是婴儿在会说话之前就有 joint attention。
4. **形态从「一个数」（价格）到「一种节奏」（乐）**；古代中国的完整形态是礼（管「分」）与乐（管「合」）。
5. **最高形态是超级目标**：化解敌意靠一起做一件非合力办不成的事，不是多接触。
6. **它也有黑暗面**：围着它就是资源，眼里只剩下它就是狂热、替罪羊与摩洛克。
7. **个人用法一句话**：别空着手进场，先拿出一个「球」。
8. **全页 `confidence: high`**：单来源，但讲稿段 100%、7 条引注全核，讲者自己交代了术语扩用。

## 定义与背景

「人与人的**地位、利益、身份、信念**各不相同，怎么还能和平共处、有效合作呢？」—— 这是全系列的总问题，**四个词分别对应本模块的四条线**（**本库判断**）。

084 是 [[modern-thinking-tools]]「模块五 参与者」的**收束讲**，行 46 自称「最后这一讲」；它把前面十六讲收在一个问题上：**有分歧的人怎么还能一起做事。** 它的编号推定链也是一条内部证据：本讲一次性点名**八讲** —— 促成合作的机制（**礼** 070 / **激励相容** 072 / **共同知识** 079）、让合作失灵的机制（**柠檬市场** 073 / **外部性** 074 / **摩洛克** 083）、人类为合作付出的代价（**可读性** 078 / **非预期后果** 081），**八条与讲次表逐条吻合**。

**孩子的球**是第三物的原型：争地盘的孩子里有一个掏出球说「踢吗？」—— 于是「**他们**没有解决掉他们原来的任何一个分歧，没分出对错，谁也不服谁。**然而他们直接就开始了非常有序的合作**」。

### 两义必须分列：边界物 ≠ 第三物

**这是本页最需要说清的一件事** —— 讲者自己声明做了概念扩展（这是一处罕见的「讲者自己交代扩用」，属正面做法，故不判「使用失真」），因此库内不应把两个词当同义词用（**这与 [[schema]] §3.9「判矛盾前先问两侧命题在不在同一层」是同一类动作**）：

| | **边界物（boundary object）** | **第三物（third object）** |
|---|---|---|
| 出处 | Star & Griesemer 1989（注 \[2\]）—— **学术概念，有正源** | **本讲自拟**（行 84 显式扩用） |
| 原始语境 | 解释不同社会世界中的人**如何在不完全共识下协作**（行 84） | 讲者把范围**扩大**到「不管促成的是协作还是竞争」（行 84） |
| 定义 | 「既可以让不同群体各取所需，又可以在不同的社会世界之间**保持共同身份**」（行 82） | 「把『人对人』的直接僵局，改造成『**人围物**』的共同局面的东西」（行 56） |
| 判据 | 各方**理解不同**但**都能拿它做自己的事** | 只要能把**人对人**变成**人围物**，就算 |
| 关系 | **第三物 ⊃ 边界物**（竞争场景是扩展进来的部分） | **本页的主题** |

讲者扩用的原话：「边界物作为一个学术概念，原始语境主要是解释……
   **我们把这个概念扩大一下**，不管促成的是协作还是竞争，只要能把人对人的僵局，
   变成人围绕着一个对象的局面，就叫『第三物』。」

**边界物为什么能协作**：伯克利脊椎动物博物馆里，科学家看到**证据**、收藏者看到**爱好**、赞助人看到**面子**、行政看到**档案**，可他们偏偏能协作得很好。**机制就是标本本身**：「**别管你是怎么理解它的，只要你可以拿它来做自己的事儿，
   那么你就可以指着它跟人协作**」。

**因此**：凡引用「边界物」，应带 Star & Griesemer 的出处；凡引用「第三物」，**不应**假装它有学术出处 —— **它是本讲的框架，不是文献里的术语**（**本库判断**）。

### 共同注意：为什么「合作不必先有共识」

本讲给的是一个**发育学**而非**道德**的答案：

| 步 | 内容 | 行号 |
|---|---|---|
| 1 | 人类**不是**先想通了再合作 | 行 62 |
| 2 | 需要的只是一种**注意力机制** | 行 64 |
| 3 | 婴儿未会说话即具备 **joint attention**：妈妈指花 → 宝宝知道**妈妈想让他注意它**，且知道**妈妈也在注意它** | 行 66 |
| 4 | 语言 / 教学 / 模仿都从这个三角关系里长出来 | 行 68 |

婴儿在会说话之前就有「**你 → 那个东西 ← 我**」：「**语言、教学、模仿，都是从「你 → 那个东西 ← 我」这个三角关系里长出来的**」。

**「人盯人」为什么不行**：「人盯着人，盯出来的是**警觉、打量、比较和防备**。
   可只要两个人同时看向第三个东西，那股绷着的劲儿就放松了。」

## 机制 / 原理

### 一张表看清「人围物」替换了什么

| | **人对人** | **人围物** |
|---|---|---|
| 注意方向 | 互相盯（行 70） | 同时看向第三个东西（行 70） |
| 盯出来的东西 | 警觉、打量、比较、防备（行 70） | 可以一起研究、摆弄、负责（行 70） |
| 需要的前提 | **共识**（先说服、先统一价值观） | **不需要** —— 只需要一个共同对象（行 88） |
| 个人动作 | 抱怨（请求别人改变）/ 讲道理（请求别人承认自己对）（行 172） | **拿出一个球**（行 170） |

### 第三物的四种形态

| 形态 | 例子 | 机制 | 行号 |
|---|---|---|---|
| **一个数** | 价格 | 把稀缺 / 需求 / 风险 / 替代品 / 预期**压缩成一个数**，陌生人不必互相解释（哈耶克，注 \[3\]） | 94–102 |
| **一个指标** | 《巴黎协定》的 2 度 / 1.5 度 | 把价值冲突**压到一个数字上**，于是可争论、可承诺、可讨价还价 | 104–106 |
| **一个台面上的东西** | 会议议程 / KPI / 报价单 / 合同 / 产品原型 / 家庭值日表 | 「任何能**摆到台面上**的东西」 | 110 |
| **一种共同的节奏** | 乐 | 「不管谁尊谁卑，大家听到的节奏是一样的，动作是一样的」（行 158） | 152–164 |

**第三物无处不在**：**价格**、**《巴黎协定》的 2 度 / 1.5 度**，以及「一份会议议程，一个 KPI，一张报价单，一份合同，一个产品原型，一张家庭值日表」；判据句是「**第三物先把价值冲突变成共同坐标，人们就能再把共同坐标变成可执行的动作**」。

**价格那一节的判据句**：「**市场的伟大之处：它不是让人类变得高尚，而是让不够高尚的人也能合作**」；「你看两个黑帮再剑拔弩张，只要有个数可以讲，双方就能坐下来谈」。

### 礼 / 乐：第三物在古代中国的完整形态（行 152–164）

| | **礼** | **乐** |
|---|---|---|
| 管什么 | **分** | **合** |
| 做了什么 | 「谁尊谁卑，谁先谁后，长幼上下，按照一定协议分得清清楚楚」（行 156） | 「一起奏乐，一起唱和，一起在同一个节拍里舞起来」（行 158） |
| 效果 | 分出秩序 ——「可光有礼，人和人之间是端着的、隔着的、绷着的」（行 156） | 「所有人融成了一个『我们』」（行 158） |
| 《礼记》 | **礼者为异。异则相敬**（行 160） | **乐者为同。同则相亲**（行 160） |

「**礼**」管「**分**」，「**乐**」管「**合**」；《礼记》：「**乐者为同，礼者为异。同则相亲，异则相敬。**」本讲对「乐」的定性是它最有价值的一处：「**乐就是那个第三物**」；「**第三物的根本作用，就是『让大家注意力同向』**」—— 礼解决**地位冲突**（069 的问题），乐解决**注意力不同向**（084 的问题）。**两者是两件事，不是一件事的两面。**

### 超级目标：第三物的最高形态（行 186–190）

**谢里夫（Muzafer Sherif）的发现**（注 \[6\]）：「两拨本来敌对的人，**光让他们多接触、多见面，关系未必会变好**；
真正能化解敌意的，是丢给他们**一件非得合力才办得成的事** —— 比如一起把陷进泥里的卡车推出来」。

**这一条与常见的「消除偏见靠多接触」直接冲突，是本节最硬的实证点。**「超级目标（superordinate goal）」是它给出的名字，也是**共享物**之外的第二条实用主意。判据句：「**共同的敌人凝聚得快，共同的目标凝聚得久**」。

### 个人怎么用的四个动作

- 核心心法：**「你想在一个局面里争取主动，就别空着手进场，先拿出一个『球』来」**。
- 对比：「只会抱怨的人是在**请求别人改变**，只会讲道理的人是在**请求别人承认自己对**。
    而一个拿得出第三物的人……**他不请求任何人，他直接改变了场上的动作**」。

| 想做的事 | 不要只说 | 先拿出 |
|---|---|---|
| 推动项目 | 「这个方向很重要」 | **一页 memo** |
| 说服同事 | 「你们应该配合」 | **一张流程图** |
| 改善家庭关系 | 「你们都得理解我」 | **一张日历 / 一份分工表 / 一个周末计划** |
| 卖创意 | （口头描述） | **一个小原型** |

判据句：「**你的主动性不是直接改变别人，而是制造一个让别人可以重新行动的对象**」。

## 边界与反例

- **讲者自己补的黑暗面**：「球可以组织比赛，也可以组织狂热。价格可以促进交易，也可以吞掉不可标价之物。
  KPI 可以让目标可见，也可以让人为了指标牺牲真实价值。共同目标可以把人变成队友，
  共同敌人也可以把人变成暴民……**一个东西可以是『大家围着它一起行动』，
  可一旦变成『大家眼里只剩下它』，麻烦就来了**」。
  **区分点很明确：是「围着它」，还是「眼里只剩下它」。** 后者就是 [[2026-09-20-scapegoat]]（080）与 [[moloch]]（083）的领地 —— 按本讲的读法，它就是第三物「黑暗面」的样本。
- **本讲不是「共识无用论」，别读成「不用讲理」。** 行 86–88 的顺序是：**先**有一个共同对象让人能一起动，**共识才慢慢长出来**。它反对的是**把共识当合作的入场券**，不是反对共识本身。**这是本页最容易被误读的一条。**
- **「共同理解是奢侈品，共同对象才是日用品」 是修辞，不是事实断言。** 它没有给任何数据；作为判据句它有力，作为经验命题它**未经检验**（**本库判断**）。
- **一处术语使用已由讲者自己交代**：行 84 把 `boundary object` 扩为 `third object`，**不判「使用失真」**；**反向要求**是本库引用这两个词时**不得混用**（见「定义与背景」）。
- **一处未核的公共事实**：行 104 的「2 度以内，力争 1.5 度之内」**未回《巴黎协定》原文核**，方向一致，**不判问题**。
- **一处素材原始形态**：本份含【有偈为证】 与 4 张图。
