# 颗粒度与因果中介（Granularity & Causal Mediation）

> **「你能理解到什么程度，才能控制到什么程度。」**（讲稿行 71）
> 模型要压到「最小描述长度」，而模型里必须含**因果箭头**；
> 真正的杠杆点往往不在终点，而在**中介变量**上 —— 行 155：「**别盯终点，盯中介。**」

## 要点

1. **开篇是一次「反伪科学」的论证**（行 35–49）：市侩哲学「癌症是气出来的」→ ACS 与 NCI 的官方口径 →
   两项大样本研究 → **「直接 vs 间接」的区分**。
2. **好调节器定理给了「为什么必须有模型」一个数学表述**（行 65）：
   **「系统的每一个好调节器，都必须是该系统的一个模型。」**
3. **「颗粒度」被操作化为 MDL 的两项之和**（行 81–87）：**模型本身的长度 + 数据补丁的长度**。
4. **因果关系的判据是「干预」而非「共现」**（行 105–109）：公鸡打鸣（共现）vs 按开关（干预）。
5. **核心链条是「生气 → 不良生活习惯 → 癌症」**（行 123–129）：
   中介不是终点，**中介才是你能按的那个按钮**。
6. **两个经典案例**：《点球成金》的「**上垒**」与足球的「**期望威胁（xT）**」。
7. **收束句**（行 185）：「**地图不是疆域。**（The map is not the territory.）」——
   与行 183「**没有绝对标准的颗粒度**……是由你的主观需求决定」配对。

## 定义与背景

- **模型是什么**（行 63）：「**模型，是事物在你头脑中的一个结构镜像**，能帮你看清楚它运行的底层机制。」
- **为什么要模型**：行 57–59 的宿管员反例 —— 没有模型只能「**无能狂怒**」。
- **同构要求**（行 69）：「你的认知结构必须**同构**于你想要控制的那个事物。」
- **理解即压缩**（行 97）：「有一句格言叫『**理解即压缩（Understanding is Compression）**』」——
  ⚠️ 该表述在信息论 / 机器学习科普中广泛使用，**但无单一首发文献**；库内
  [[compression-as-intelligence]] 已把它当作**命题而非引注**处理。

## 机制 / 原理

### ① 颗粒度 = MDL 的两项之和（行 77–97）

| 档位 | 讲稿的天气例（行 89–91） | 后果 |
|---|---|---|
| **过拟合** | 描述细到能记住每一朵云 | 模型太长，不可迁移 |
| **欠拟合** | 只说「今天天气不错」 | 数据补丁太长，无预测力 |
| **恰到好处** | 压到最小描述长度 | 两项之和最小 |

- **奥卡姆剃刀**（行 81）：「如无必要，勿增实体」—— 讲稿只说「你早就听说过」，**未声称出处**。
  ⚠️ **该拉丁原文（*Entia non sunt multiplicanda praeter necessitatem*）不在奥卡姆自己的著作里**，
  是后世的归纳表述 —— 属「表述被后人归纳」，**与「张冠李戴」不同型**。
- **MDL** 由 **Jorma Rissanen 于 1978 年**提出，两项式 = `L(M) + L(D|M)`，与讲稿表述一致。
  ⚠️ **素材未点名 Rissanen** → 弱引注，但内容准确。
- 行 95 的股市例：**100 个理由**（过拟合）vs「**流动性收紧导致风险资产重估**」（恰到好处）。

### ② 因果的判据是干预，不是共现（行 101–117）

| 概念 | 行 | 内容 |
|---|---|---|
| 珀尔 | 103 | **图灵奖得主朱迪亚·珀尔**，*The Book of Why*（2018）中文版《为什么：关于因果关系的新科学》 |
| **do-operator** | 105 | 「我**强行介入**……单方面让事件 X 发生，而这时候事件 Y 发生的概率增加了」 |
| 反例（共现） | 107 | 公鸡打鸣 —— 它叫了天会亮，但**你不能靠让它闭嘴来阻止天亮** |
| 正例（干预） | 109 | 按开关 —— 你按，灯就亮 |
| 因果图 | 111 | 把变量用箭头串成因果关系图 |
| 限度 | 117 | 「任何模型都不可能穷尽一个事物中所有的因果关系」 |

### ③ 中介变量：别盯终点，盯中介（行 119–155）

| 案例 | 行 | 链条 |
|---|---|---|
| **癌症** | 121–129 | **生气 → 不良生活习惯 → 癌症**（NCI 直接点名这条中介链） |
| **棒球** | 135–145 | **（击球 + 选球眼光）→ 上垒 → 得分 → 赢球** |
| **足球** | 149–153 | 不是助攻，而是「**倒数第二脚、第三脚传球**」→ **期望威胁（xT）** |
| **学习** | 165–169 | **（时间 + 注意力）→ 记忆编码 → 提取 → 成绩** |

- 行 129 的反事实检验：「如果你虽然情绪不佳，但依然能坚持锻炼并控制饮食，
  那么你就不会因为『生气』而得癌症」—— **这是把中介识别出来的操作性判据**。
- 行 131：「**有个好模型，你才能抓住控制点。**」
- 足球那一脚把进球概率从 **2%** 提到 **30%** —— ⚠️ 素材未点名提出者，
  外部核查确认为 **Karun Singh 于 2018 年**提出的空间马尔可夫链模型（量级与 xT 矩阵一致）。
- 行 171–177 的**公司管理**例给出了颗粒度的双向失败：**只盯收入 = 欠拟合，全盯中介 = 过拟合**。

## 边界与反例

- **一处弱引注（逐条标，不整页降级）**：行 45「**更有研究发现**，愤怒控制、负面情绪与癌症风险总体无显著关联」——
  **无年份、无机构、无期刊**。方向与 2026 年伞式综述一致（心理压力与癌症**发病**无显著关联；
  但与癌症**死亡**率显著相关），**但归属不可追溯**。按 `AGENTS.md` 4.1 标「**（未验证）**」。
- **一处不可追溯（格言，非伪引注）**：「理解即压缩」**素材自称「格言」，未指向任何具名来源** ——
  它没有制造「有出处」的假象，故**不构成伪引注**。
- **「地图不是疆域」有正源但素材未点名**：**Alfred Korzybski 1931** 年提出（*A Non-Aristotelian System…*）。
- **与 [[cognitive-load-theory]] 的辨析（必须显式说明，避免下游误并）**：
  本讲的「**过拟合 / 欠拟合**」是统计学术语，与 012 讲把「**认知欠载**」定为失败态**不是同一处问题** ——

  （可编码部分建模型、不可编码部分靠学徒制），**但素材从未讨论这条边界**。
