# 路径创造（Path Creation）

> **「路径创造」是既有学术术语**（Garud & Karnøe 2001，素材已署名），
> 但本讲真正可迁移的是它把这个术语翻译成的**三步操作框架「造路 / 导流 / 退役」**（**讲稿自拟**）。
> 机制的核心是把「**存量 vs 增量**」重新切开：**不动任何人的存量、不宣布旧制度是错的，
> 只把新增的人 / 钱 / 项目 / 客户导进新路，等旧路自己断供**。

## 关键要点

1. **术语有出处且已署名**：**Garud & Karnøe 2001** —— **不是万维钢自造词**（术语归属专段）。
2. **但操作框架是讲稿自拟的**：**「造路 / 导流 / 退役」三步** —— ⚠️ **引用时须分清哪层是学术、哪层是讲稿。**
3. **核心机制是把「存量 vs 增量」切开**：不动存量、不宣布旧制度错
   **只把新增的导进新路，等旧路自己断供。**
4. **它绕开了变革最常见的阻力**：**不需要说服既得利益者** —— 因为他们的存量没被动。
5. **「退役」是第三步，也是最容易被漏掉的一步**：新路通了之后，旧路要**主动断供**，否则双轨并行会拖住。
6. **它是「变革」的操作面**：[[adaptive-cycle]] 讲**变革为什么必然发生**，本页讲**怎么主动做**。

## 定义与背景

- **路径依赖 vs 路径创造**：
  | | 路径依赖（path dependence） | 路径创造（path creation） |
  |---|---|---|
  | 对历史的态度 | **被既有路径锁住** | **可以主动造一条新路** |
  | 行动主体 | 被动 | **主动** |
  | 本讲的处理 | 作为对照被提及 | **作为工具展开** |
- **为什么「不动存量」是关键**：变革的阻力**主要来自存量受损者的反抗**，而不是新方案不够好。
  **绕开存量 = 绕开阻力。**
- **⚠️ 本页必须标注的两层**：
  ① **术语**（Garud & Karnøe 2001）是学术的；
  ② **三步框架**（造路 / 导流 / 退役）是**讲稿自拟**的 —— 两者不能混为一谈。

## 机制 / 原理

### 三步框架（讲稿自拟）

| 步 | 做什么 | 关键 |
|---|---|---|
| **造路** | 先建一条新路（新制度 / 新流程 / 新市场） | 不宣布旧路是错的 |
| **导流** | 把**新增**的人 / 钱 / 项目 / 客户导进去 | **只动增量，不动存量** |
| **退役** | 新路跑通后，让旧路**主动断供** | 不做这步就会双轨并行 |

**核心洞察**：**变革不必是「推翻」，可以是「断供」。**
旧制度不是被废除的，是**因为没有新增流量而自然枯竭的**。

### 为什么这比「说服」有效

**说服需要对方承认自己错了** —— 这是最难的一步。
**导流不需要**：它只改变**新增资源的去向**，不要求任何人认错。
**代价**：时间更长（要等旧路自然枯竭），且**只适用于有持续增量的系统**。

## 边界与反例

- **⚠️ 它的适用前提**：**必须有持续的增量**可导。
  在**零增长或收缩**的系统里，「导流」没有东西可导 —— **此时只能动存量，框架失效。**
  **素材未讨论这一层，本库登记。**
- **⚠️ 三处邓小平原话与一处顺口溜未取回来源**（改革开放部分）—— 标（未验证）。
  **注意**：这不代表它们不真实，只代表**本轮没取到可引来源**。
- **⚠️ 「退役」这一步有政治成本**：旧路断供会让**仍在旧路上的人**受损 ——
  即使他们的存量当初没被动。**素材未讨论，登记。**
- **⚠️ 别把它读成「永远不要硬碰」**：本页给的是**在阻力大时的一种路径**，
  不是「存量永远不该动」的原则 —— 与 [[hard-constraints]] 那条「有些约束绕不开」并存，需分情况。
