# Alpha 与 Beta（阿尔法与贝塔）

> **Beta = 搭市场顺风车应得的那部分回报；Alpha = 扣除市场因素后、超出市场共识的超额收益**。
> 讲稿把它借用为一句判词：**「Beta 只能让你在市场中存活，只有 Alpha 才能给你积累经济租」**。
> Alpha 是**动能**（主动出击、纠正错配的动作），经济租是**势能**（动作的战果凝固成的防御堡垒）。

## 关键要点

- **金融学定义**：Beta 是一只基金对市场共同风险的暴露；Alpha 是扣除市场因素后的**风险调整后超额收益**。提出者 CAPM（Sharpe 1964 / Lintner 1965）与 Jensen's alpha（Jensen 1968）**素材未点名**，系 sources 页外核补记。
- **讲稿的借用**：Beta = 搭顺风车得到的收益；Alpha = 超出市场共识、靠更高一层的认知 / 判断 / 动作硬多拿到的那部分。
- **判词**：**Beta 只能让你存活，只有 Alpha 才能积累经济租**；「你所有的勤奋都会沉没到 Beta 里」。
- **错配是 Alpha 的源头**：新古典假设均衡 → 无超额利润；哈耶克 1968「竞争是一个发现程序」+ 柯兹纳「企业家发现 / 警觉性」→ 世界充满**错配（Mismatch）**。
- **波特 1996 的二分**：运营效益 = 把同样的事做得更好（可被学会，是 Beta）；战略定位 = 换一套打法（不可模仿，是 Alpha）；战略定位必须伴随痛苦的**取舍（Trade-offs）**。
- **公司视角的反馈**：核心能力很容易反过来变成**核心刚性** ——这是 [[explore-exploit-tradeoff]] 在战略层的落点。

## 正文

### 金融学的 Alpha / Beta

**Beta** 是一只基金对**市场共同风险**的暴露，代表它「跟着市场走」应得的那部分回报。
**Alpha** 是在扣除这部分市场因素之后，基金获得的**风险调整后超额收益**。

这套定义出自标准金融学：Beta（系统性风险）来自 CAPM（Sharpe 1964 / Lintner 1965），
Alpha（Jensen's alpha）来自 **Jensen 1968**（*Journal of Finance* 23(2):389–416）。
**素材未点名提出者**，以上归属系 sources 页外核补记，未收录进 `raw/`。

讲稿的借用很清楚：Beta 是搭市场顺风车得到的收益，Alpha 是「超出市场共识、靠更高一层的认知、判断和动作，硬生生多拿到的那部分收益」。

### 从「不信 Alpha」到「错配」

新古典经济学倾向于假设**完全信息、绝对理性、均衡**——那样谁都没有超额利润的空间。
**1968 年哈耶克**提出「**竞争是一个发现程序**（Competition as a Discovery Procedure）」：
现实世界的知识高度分散，市场不透明，永远存在被低估的需求、被闲置的资源和没被利用的机会。
于是世界充满「**错配（Mismatch）**」，市场普遍**不均衡**。

**柯兹纳**（奥地利学派）在此基础上提出「**企业家发现**（Entrepreneurial Discovery）」：
真正的企业家具备高度「**警觉性**（Alertness）」，能察觉错配并通过**纠正错配**赚取利润。
判据：**只有你在纠正错配，这就是你的 Alpha；大家都在开公司纠正类似错配，那就只是 Beta**。

### 战略定位 vs 运营效益（波特 1996）

**1996 年**哈佛商学院教授**[[michael-porter|迈克尔·波特]]**发表《什么是战略？》（What Is Strategy?），
提出「**运营效益（Operational Effectiveness）**」与「**战略定位（Strategic Positioning）**」是两回事：

| | 运营效益（≈ Beta） | 战略定位（≈ Alpha） |
|---|---|---|
| 做什么 | 在日常活动上做得比对手更好（更快、更省） | 执行与对手完全不同的活动，或以完全不同方式执行 |
| 可否被模仿 | 原则上对手也在做，迟早学会 | 对手**无法模仿** |
| 例 | 同样航线把调度做精、周转加快、采购压狠 | 西南航空：只做短途高频、单一机型、简化服务，围绕「快速周转」重设整套运营系统（行 87） |

**波特的警告**：搞战略定位就一定要有**痛苦的取舍（Trade-offs）**——必须专注某个错配、放弃其他市场。
由此讲稿推出一条锋利判断：**「用 AI 降本增效根本就不是战略」**，因为同质化 → 价格战 → 利润率蒸发 → 没钱研发新 Alpha。
**「低利润率是一种耻辱。降本增效不是进攻而是防守。」**

### 三本账：现金 / 能力 / 位置

讲稿把公司想成三本账：

- **现金账**（管今天）：KPI、周转率、毛利率；
- **能力账**（管明天）：今天这点利润买回了什么别人一时学不走的能力；
- **位置账**（管后天）：能力沉淀成品牌、标准、默认入口、网络效应与信任。

**「利润是今天的结果，能力是明天的原因，位置是后天的统治」**——形成统治，那也就是经济租。
所以：**Alpha 是动能，经济租是势能**；战果转化成品牌、专利、网络效应等防御堡垒时，就凝固成经济租。

### 护城河与竞争优

「超出市场共识的那部分收益」与 [[multiplicative-world]] / [[heavy-tailed-distribution]] 同构 ——
平庸的 Beta 挤在分布中段，Alpha 才是尾部的那一次。
把 Alpha 凝固成品牌、专利、网络效应、声誉、关系、用户习惯
就是 [[symbolic-capital]] / [[structural-holes]] / [[social-capital]] 在商业侧的形态，也就是[[economic-rent|经济租]]。

### 核心刚性：战略层的探索-利用反馈

公司若陷入价格战便无钱研发 Alpha；但运营良好、资金充足的公司**多数也不会主动去寻找新 Alpha**。
这里回指本课模块一讲过的「**探索与利用（Explore / Exploit）的权衡**」——
「当前打法已经很熟练、已经优化得很好」，于是不愿挪开资源去探索新东西；
**核心能力很容易反过来变成核心刚性，不可挑战**。
讲稿由此解释：这就是为什么**巨头会给后来者留下机会搞「颠覆式创新」**。

> [!note] 术语归属
> 「核心刚性（core rigidities）」出自 **Leonard-Barton 1992**（*SMJ* 13(S1):111–125），
> 「颠覆式创新」出自 Christensen 系。**素材均未点名**，故未发生「把 Leonard-Barton 的功劳记到克里斯坦森名下」的错位（sources 页核查表 #8 / #9）。

### 五步心法（讲稿自拟）

讲稿把上面拼成一套「从 Alpha 到经济租」的心法，**系讲稿自陈的总结、非既有框架**（sources 页核查表 #17）：

**错配 → 认知 → 执行 → 占有 → 重构**。
其中讲稿自陈**第二步「凭什么由你来纠正」最关键**。
对「有独特的东西才有 Alpha，而 Alpha 不就是独特的东西吗」这一同义反复之诘，回答是：
**异质性特点本身不构成 Alpha，只有「组合起来 + 放到具体错配上」才可能形成 Alpha**。
