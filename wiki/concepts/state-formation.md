# 国家形成（State Formation）

> 「政府可不是读书人的发明。历史的真相更接近于……**政府起源于强盗**」（行 44）——
> 「他们改变的只是**时间偏好**。强盗一旦学会长期主义，就开始像统治者；**统治者一旦忘记约束，也随时能退回成强盗**」（行 66）。
> 本讲最重要的一句判据：「**限制权力不是写在纸上，而是写在权力分布里**」（行 194）。

## 要点

1. **政府的起源不是契约，是保护费**（行 44–56）：**奥尔森的「流寇 → 坐寇」**（注 \[1\]）——
   抢劫不可持续（「到了第二年，你再想抢都没得抢」，行 52），于是「干脆我把这个村占了，给村民留口活路……
   **我每年只从他们身上抽三成**」（行 56）。
   **关键机制是时间偏好的改变**（行 66）—— 见「机制 / 原理」。
2. **韦伯的国家定义**（注 \[3\]，行 76）：国家是「在一定疆域内成功主张『**合法物理暴力垄断**』的人类共同体」。
   **政府是执行面**（行 78）。
   **政府与其他组织的唯一区别**（行 90）：「不在于它服务更好、不在于它更仁慈、甚至不在于它更『为人民』——
   而在于它拥有**最终强制权**」。
3. **国家是战争制造出来的**（蒂利，注 \[4\]，行 102–106）：「**战争制造国家，国家制造战争**」。
   逻辑链：坐寇互斗 → 建正规军 → 多收税 → 养官僚。
4. **谷物是理想征税对象**（斯科特，注 \[5\]，行 110–118）：可估产、有固定收获季、高度可量化、可储存运输，
   **且「种谷物的农民只能被绑定在土地上，想跑都没地方去」**（行 114）。
   由此解释**为什么欧洲难以统一**（行 124）：欧洲「没有一个像华北平原那样的单一农业心脏」。
5. **前现代国家的本质是家产制（patrimonialism）**（行 134–138）：「政府不是什么公共服务公司，而是**统治者的家产**」；
   「安全和机会不是由制度平等提供，而是由**权贵私人分配**」。
6. **两个死循环**：① **权力与猜忌的循环**（行 142）；
   ② **黄宗羲定律**（秦晖总结，注 \[10\]，行 144–156）—— 见「机制 / 原理」。
7. **三个演化节点**（行 162–194）：**1215《大宪章》**（第一次承认「王在法下」，**第 61 条把「造反」变成制度化权利**，行 164–170）；
   **1688 光荣革命**（《权利法案》剥掉国王三样权力，行 172–174）；
   **1787 美国制宪**（**唯一有「思想家顶层设计味道」的一个**，行 186–190）。
8. **本讲最重要的一句判据**：「**限制权力不是写在纸上，而是写在权力分布里**」（行 194）。
9. **收尾的转问**（行 198–204）：「现代人必须学会从问『**这个人好不好**』、『这个政府好不好』，
   改为问『**我们这个制度行不行**』」（行 200）。

## 机制 / 原理

**流寇 → 坐寇的时间偏好机制**（行 44–66）：

| | 流寇（roving bandit） | 坐寇（stationary bandit） |
|---|---|---|
| 时间偏好 | **极高**（捞一把就走） | **低**（长期经营） |
| 对治下人口的态度 | 消耗性资源 | **生产性资产** |
| 税率 | 竭泽而渔 | 「我每年只从他们身上抽三成」（行 56） |
| 提供什么 | 无 | **保护**（因为要长期收税） |
| 判据句 | —— | 「**强盗一旦学会长期主义，就开始像统治者；统治者一旦忘记约束，也随时能退回成强盗**」（行 66） |

**黄宗羲定律（秦晖总结，行 144–156）**：

```
轻徭薄赋
  → 官僚扩张 + 皇上好大喜功
    → 加税
      → 杂税名目层出不穷
        → 并税改革（把杂税并进正税）
          → 再涨（因为官僚规模没减）
            → 「积累莫返之害」（行 154）
```

> **本页判断**：这条循环的**现代表述**在 076 讲的**软预算约束**（见 [[2026-09-20-soft-budget-constraint]]）——
> **两讲的接续是「本库判断」，已登记待裁定**（见「待办 / 开放问题」）。

**三个约束权力的节点**（行 162–194）：

| 节点 | 做成了什么 | 机制 |
|---|---|---|
| **1215《大宪章》** | 第一次承认「**王在法下**」 | **第 61 条把「造反」变成制度化权利**（行 164–170） |
| **1688 光荣革命** | 《权利法案》剥掉国王三样权力 | 限制任意征税 / 没收 / 违约（行 172–174） |
| **1787 美国制宪** | **唯一有「思想家顶层设计味道」的** | 事前设计（行 186–190） |

## 边界与反例

- **⚠️ 「政府起源于强盗」不是本讲的完整主张**：本讲同时给出**韦伯的定义**（合法暴力垄断）与**蒂利的机制**（战争制造国家）。
  三者的关系是：**奥尔森解释动机（为什么收保护费而非抢光），蒂利解释路径（为什么会长成国家），韦伯解释判据（什么算国家）。**
  **只引其中一条会失真。**
- **一处与库内页面的明确划界**：**本讲与 [[hume-guillotine]] 无关**（虽同为政治哲学）——
  sources 页明确「**不建立关联**」。**本页据此不建立该链接。**
- **一处未裁定的接点**：075 行 114 的「**谷物可量化、农民被绑定在土地上**」正是 078 讲「**可读性**」的**前身**
  （见 [[2026-09-20-legibility-and-metis]]）。**两讲相隔三讲，概念同源** ——
  sources 页判「**本库判断，待裁定**」是否建立显式对照。
- **「家产制」与「坐寇」不是同义词**：坐寇讲的是**动机**（时间偏好），家产制讲的是**产权结构**（政府 = 统治者的家产）。
  **本页合并两者，但保留区分。**
- **一处本讲未处理的张力**：本讲把「美国制宪」称为唯一有顶层设计味道的一个，
  但**它仍是 1787 年一群有产者的产物** —— **本讲未讨论其代表性问题**。**本库登记，不引申。**

## 2026-09-20 回填（模块五 参与者 · 本批 13 份清单）

> 来源：[[2026-09-20-slow-variables]]（082）的「回填清单」建议（该条原标「**本库判断**」）。

- **082 行 122–148 是本页「黄宗羲定律」的一个完整实例（本库判断）。** 本页依据的 075 讲
  给出黄宗羲定律的**抽象过程**（行 144–154：加税 → 杂税名目 → 并税改革 → 再发明新杂税 →
  「积累莫返之害」→ 流民 → 民变 → 王朝崩溃 → 再来一遍）；
  082 给的是**一个具体皇帝的完整账目**：武帝接手文景两代家底（行 128），
  随后政府「把手伸向资源、价格、流通和民间财富」（行 132），
  082 行 134–144 逐条列出**六条汲取手段** —— 货币政策（白鹿皮币 / 白金币）、
  税收政策（算缗 / 告缗）、产业政策（盐铁官营 / 酒类专卖）、价格政策（均输 / 平准）、
  劳役兵役、司法与产权（酷吏政治与告发机制）。
  **判据句（082 行 146）：「这些本质上都是把国家的信用给变现。短期看，财政有了钱；
  长期看，慢变量和稳定预期被消耗殆尽。」**
  结果见行 148 的正史引文：「**海内虚耗，户口减半**」。
- **两讲合起来的价值**：本页有**机制**，082 有**一次完整的、可核到政策条目的实例**。
  **⚠️ 082 未使用「黄宗羲定律」一词**，关联由本库建立，故**不列入本页 `sources`**。
