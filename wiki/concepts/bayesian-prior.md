# 贝叶斯先验（Bayesian Prior）

> **先验就是你的成见 —— 但成见是认知的起点，而且这个起点可以被量化、被更新、被审计**（讲稿）。
> 三个动作：**设定先验 → 用证据更新 → 永不给先验设 0 或 1（克伦威尔法则）**。
> 收束句：**「先验既是我们的财富，也是我们的囚笼。」**

## 关键要点

1. **公式与四项术语**：`P(H|E) = P(E|H)·P(H) / P(E)` ——
   **先验概率 / 后验概率 / 总概率 / 似然度**（标准表述，已核）。
2. **罕见病算例是本节的技术核心**：发病率 **0.1%**、灵敏度 **99%**、误报率 **1%** → 后验 **1/11**。
   **本库已独立复算，与公式法一致**（见「机制」）。
3. **它要纠正的直觉**：**「如果先验原本很低，哪怕证据很强……你的后验概率也还是不高。」**
4. **频率主义 vs 贝叶斯主义**：前者认为概率是**世界的客观属性**，后者认为概率是**信念的度量**。
   行 93 是全讲最哲学的一句：**「频率主义者是世界的旁观者，而贝叶斯主义者则是世界的参与者。」**
5. **两种错误各有名字**：①**完全没有先验**（听风就是雨）；②**先验不可动摇**（把概率设成 0 或 1）。
6. **克伦威尔法则**：出自 **1650 年**克伦威尔致苏格兰教会的信 ——
   「我恳求你们，在基督的慈悲下，**想一想你们可能错了**」。
   行 155：**「哪怕你特别特别相信一个事情，你总可以把它的先验概率设成 99.999%，但是不要设成 1。」**
7. **它显式接入库内既有的「自由能原理」**，并**补上缺失的另一半 —— 主动推断**。
8. **两个应用**：垃圾邮件过滤（「程序不是在瞎猜，而是在**记账**」）；
   LLM。

## 机制 / 原理

### 罕见病算例（行 67–79）—— 讲稿的「笨办法」

1000 人体检：**真阳性 ≈ 1**、**假阳性 ≈ 10**、总阳性 **11** → `P(E) = 11/1000` → **`P(H|E) = 1/11`**。
公式法复算：`P(E) = 0.99×0.001 + 0.01×0.999 = 0.01098`，`P(H|E) = 0.00099/0.01098 ≈ 0.0902 ≈ 1/11.09`。
**两法一致** —— 这是本页最硬的一处内部一致性检查。

### 克伦威尔法则：给先验留一道缝（行 149–155）

| 错误 | 表现 | 判据 |
|---|---|---|
| ① 完全没有先验 | 听风就是雨 | 「那谁还敢指望你呢？」（行 147） |
| ② 先验不可动摇 | 把概率设成 **0 或 1** | 克伦威尔法则：留到 **99.999%** 也要留 |

### 主动推断：改变环境，而不是改变模型（行 133）

「**除了更新先验（也就是知觉推断），你还有另一个选项，那就是主动推断：
你可以改变环境，让环境适应你的先验。**」

### 两个应用（行 101–123）

- **垃圾邮件过滤**：先验 20% + 逐词更新 → 「程序不是在瞎猜，而是在**记账**」。
- **LLM**：「现在的 AI 大语言模型，其实就是一个**巨型的贝叶斯预测机**」；
  「你给模型一段提示词，你就是在给它输入观测证据，**强迫它更新后验概率**」；
  「AI 公司会设法给模型一个**不可轻易被提示词推翻的先验**……这就是『**对齐**』」。

## 边界与反例

- **⚠️ 一处引文归属查无实据**（核查表 #3）：行 135 把「**当事实改变时，我改变我的想法。先生，你呢？**」
  作为**凯恩斯的直接引语**给出。**Quote Investigator 的追查结论：最早的强匹配不是凯恩斯，
  而是 Paul Samuelson 1970 年在 *Meet the Press* 上的说法**；凯恩斯 1924 年有**相近但措辞不同**的表述；
  两位凯恩斯权威 **Skidelsky 判其为 apocryphal、Moggridge 明说「there is no evidence」**。
  → **归属不可追溯（不是「已核实不存在」）**，逐条公示，**不整页降级**。
  **这是本库 [[viktor-frankl]] 之后的第二处「引文归属追查」案例。**
- **⚠️ 一处与学界通说不符**（核查表 #4）：行 83 称贝叶斯「**在 1740 年代推导出了这个公式**」。
  贝叶斯 **1761 年去世**，其论文由挚友 Richard Price 在遗稿中发现，**1763 年提交、1764 年发表**；
  **贝叶斯本人终生未发表该成果**。**没有任何一手证据支持「1740 年代推导」。**
  读者自行查证即可推翻 → 属「**读者能自己发现**」的一类，**公示而不降级**。
- **一处措辞不精确**（核查表 #5）：行 83 说贝叶斯方法「**成为范式**发生在 1920–30 年代」，
  而通说把这段时期描述为贝叶斯进路**被 Fisher / Neyman 夹击、进入「日食期」**的时期；
  「成为范式」的年份更接近 **1950 年代起**。**记为措辞不精确，非事实错误。**
- **一处措辞强度高于证据强度**（核查表 #8）：行 117「LLM **其实就是一个**巨型的贝叶斯预测机」——
  这是**类比主张**，学界对「LLM 是不是贝叶斯预测机」有争议。素材用断言式措辞，**标（未验证）**。
