# 慢变量（Slow Variables）

> 「**政府不是好在『做什么』，而是好在『不做什么』**」（行 42）——
> 一个真心想做好事的政府能给社会最贵的礼物，「不是补贴，不是一项又一项大工程……而是一种朴素到几乎没人会把它当成政绩的东西 ——
> **「稳定预期」**」（行 52）。
> 判据句：「**有的政府吃慢变量的利息，有的政府消耗慢变量的本金**」（行 118）。

## 要点

1. **引子：政府的两面**（行 40）：「政府是人世间最强大的力量。它可以办成很多好事，但它也可以通过
   **寻租、软预算约束、强制可读性和非预期后果**这些机制，造成坏的结果」。
   **⚠️ 这一句是本批最强的一条编号旁证**（四个被点名者分别落在 075 / 076 / 078 / 081）。
2. **电商平台类比**（行 44–50）：你把钱投下去，平台算法变了，店一夜之间没了流量 ——
   「那你还会主动搞长期投资，研究新产品吗？**你真正应该研究的是平台老板**」（行 48）。
   **国家也是这样**：「企业家、投资人、科学家、打工人、学生，应该把注意力用于市场，而不是盯着政府」（行 50）。
3. **市场优于官办的三个概念**（行 60–64）：**哈耶克的「价格信号」**（局部知识压缩成可行动信号）；
   **熊彼特的「创造性破坏」**（新人挑战旧人）；**科尔奈的「软预算约束」**（市场是硬预算约束，失败是真的失败）。
4. **香槟集市的真实历史**（注 \[1\]，行 70–74）—— **本讲的一处「纠错」**：
   自由派常引十二三世纪法国香槟集市，说市场秩序可以靠商人法、私人法官和声誉机制**自发生成**；
   「**然而那不是真实历史**」（行 72）—— 真实历史是背后有安全通行、纠纷裁判、契约执行、度量衡管理，还有**香槟伯爵提供的保护**。
   **判据句**：「**自由市场不是凭空长出来的野草，而是一套高度精密的公共基础设施**」（行 74）。
5. **制度经济学**（注 \[2\]，行 76）：要让两个陌生人敢做交易，必须有制度保障。
6. **四层规则**（行 82–92）—— 见「机制 / 原理」。**判据句**：「**这些规则，就是平台的慢变量**」（行 92）。
7. **快变量 / 慢变量**（霍林，注 \[3\]，行 98）：快变量**变化快、看得见、容易被人拿来考核**；
   慢变量**变化慢、不显眼，却决定整个系统有没有「韧性（resilience）」**。
8. **两个比喻**（行 102–110）：**湖**（藻类 / 水质 / 鱼群 vs 流域植被 / 物种结构 / 底泥磷含量 / 自净能力）；
   **种地**（庄稼 vs 土壤的再生能力）——「这季是长得多，以后可就长不好了」（行 110）。
9. **国家的快慢变量**（行 106）：**经济增速、财政收入、就业数字、行业景气 = 快变量**；
   **产权、法治、信用和社会信任 = 慢变量**。
10. **中心案例：西汉文景之治 → 汉武帝**（行 122–156）—— 见「机制 / 原理」。
    **判据句**：「**这些本质上都是把国家的信用给变现**」（行 146）；
    「**武帝的伟业，不但是从文景之治的积累中提款，而且是把家底都给卖了**」（行 156）。
11. **四个西方教训**（行 162–168，**全部无引注**）：戴克里先 301 年《最高限价敕令》；
    腓力二世 1557–1596 年多次暂停偿债；尼克松 1971 年工资价格冻结；特拉斯 2022 年「迷你预算」。
12. **政府该办多少事：四种主张**（行 182–188）：只维护慢变量（注 \[4\] Gilder）；
    做市场做不好的事（教育 / 医疗 / 基础科研 / 公共卫生 / 基础设施 / 环保 / 标准制定）；
    **马祖卡托的「塑造和创造市场」**（注 \[5\]）；**格申克龙的「冷启动」**（注 \[6\]，「你要下场当球员也不是不行，
    **前提是球场还不存在**」）。
    **本讲的判据句**：「不管你怎么搞，**政府首先必须是慢变量的建设者，而不能是破坏者**」（行 190）。
13. **反直觉规律**（注 \[7\]，行 192–200）：「**如果政府能尊重慢变量，不搞横征暴敛，它的战争能力其实不会减弱，反而会增强**」。
    1688 年光荣革命后（注 \[8\]）：「国王被关进了笼子，但国家并没有变弱！」
    **判据句**：「**一个受限制、不能赖账的政府，反而是一个更有力量的政府**」（行 200）。
14. **老子**（行 204–212）：**「无为而治」的本意**（行 212）「不是政府什么都不做，而是政府守住自己的层级：
    **不与民争利，不与商争业，不以裁判身份下场经营，不用权力改写价格信号，不把社会的试错空间和自我演化能力收归自己**」。
15. **收尾**（行 214–216）：「政府不应该是舞台上的主角。它应该是**剧场里的灯光、消防、秩序、声学和安全出口**。
    **没有它戏就演不下去。但观众不会天天注意它。**」

## 定义与背景

**定义**：**慢变量 = 变化慢、不显眼，却决定系统有没有韧性的那些条件**（霍林）。

**它在本课内的位置**：082 是「模块五 参与者」的**收束讲**。
本讲行 40 一次性回指 075 / 076 / 078 / 081 四讲，**是本批最强的一条位置环**。

**本页与库内既有页面的定位差**：本页是**「政府应该维护什么」的正面论述**；

[[2026-09-20-soft-budget-constraint]] 是「什么样的局会让坏变得划算」。

## 机制 / 原理

**平台的四层规则**（行 82–92）：

| 层 | 管什么 | 判据 |
|---|---|---|
| **身份层** | 谁能进入，谁有资格成为参与者 | 参与资格 |
| **交易层** | 产权、契约、货币、税制和价格信号怎么运行 | 交易能否发生 |
| **裁判层** | 冲突如何解决，程序是否公开，申诉是否可能 | 纠纷能否了结 |
| **结算层** | 货币信用、财政信用、执法信用 | **「最后的承诺到底算不算数」** |

> **判据句**：「**这些规则，就是平台的慢变量**」（行 92）。

**快变量 / 慢变量对照**（行 98–118）：

| | 快变量 | 慢变量 |
|---|---|---|
| 变化速度 | 快 | 慢 |
| 可见性 | **看得见** | 不显眼 |
| 被谁用 | **容易被拿来考核** | —— |
| 国家层的例子 | 经济增速、财政收入、就业数字、行业景气 | **产权、法治、信用、社会信任** |
| 湖的例子 | 藻类、水质、鱼群数量 | 流域植被、物种结构、底泥磷含量、自净能力 |
| 种地的例子 | 庄稼 | **土壤的再生能力** |
| 判据句 | —— | 「**有的政府吃慢变量的利息，有的政府消耗慢变量的本金**」（行 118） |

**汉武帝的六条政策（每一条都在动慢变量）**（行 134–144）：

| # | 领域 | 政策 | 后果 |
|---|---|---|---|
| 1 | 货币 | 白鹿皮币、白金币 | 「**货币信用被反复折腾**」 |
| 2 | 税收 | **算缗 / 告缗** | 「商人的**产权预期**被打穿」 |
| 3 | 产业 | **盐铁官营、酒类专卖** | 政府亲自下场做最大的商人 |
| 4 | 价格 | **均输、平准** | 「价格不再只是供求信号，还要服从国家财政和战争需要」 |
| 5 | 劳役兵役 | 大量人口被抽离生产 | 「家庭原本**连续经营的计划**被随时打断」 |
| 6 | 司法 | **酷吏政治和告发机制** | 「还要担心政策失败、关系失败、站队失败」 |

> **正史引文**（行 148）：《汉书·食货志》「民人给家足」→「**功费愈甚，天下虚耗，人复相食**」；
> 《汉书·昭帝纪》「**海内虚耗，户口减半**」。
