# Naval Ravikant（纳瓦尔·拉维坎特）

> **硅谷投资人 / 思想家，库内首次出现**。他是「**不需要授权的杠杆（permissionless leverage）**」这一表述的**正源**，
> 也是「**四种杠杆（劳动力 / 资本 / 代码 / 媒体）**」框架的提出者。
> 060 讲（[[2026-09-19-business-leverage]]）借他的洞见收束「个人上哪儿找杠杆」这一问题。

- **类型**：人物（投资人 / 创业者 / 写作者）
- **别名**：中文素材作「纳瓦尔」
- **外部链接**：—

## 是什么

硅谷投资人。其知名框架是**四种杠杆**：**劳动力（labor）/ 资本（capital）/ 代码（code）/ 媒体（media）**，
其中**代码与媒体是「不需要授权的杠杆」**——劳动力需被领导同意、资本需银行或投资人同意，
而代码和媒体不需要任何人的许可。

060 讲只引用了其中一条洞见（`permissionless leverage`），并用它回答「一个人上哪儿找杠杆」：
「你最好的起步，就是调动这些杠杆的能力」。

> [!warning] 与 060 讲「六种杠杆」的关系必须分清
> 060 讲给出的**六种杠杆**（劳动力 / 机器 / 基础设施 / 知识产权 / 网络 / 债务）是**讲稿自拟的扩展**，
> **不是纳瓦尔的框架**——它只借用了 Naval 的「劳动力」一项，把「资本」换成「债务」、
> 把「代码 / 媒体」拆成「知识产权 / 网络」，另加「机器 / 基础设施」（sources 页核查表 #10）。
> **素材并未把六种挂到 Naval 名下**，故不构成「改写既有框架而误标为既有」。
> 引用时必须显式写明：**六种是讲稿自拟，Naval 是四种**。
