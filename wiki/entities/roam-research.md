# Roam Research（双向链接笔记工具的引爆点）

> 把双向链接从「历史遗产」变成「当代主流」的那款工具。它以「块级双向链接」为核心，把笔记组织成一张图而不是一棵树。在本知识库中，它的意义是**时间坐标** —— 它标记了双向链接复兴的起点。

- **类型**：工具 / 产品
- **外部链接**：https://roamresearch.com/
- **创始人**：Conor White-Sullivan

## 是什么

一款「面向网络化思考（networked thought）」的笔记工具，官网自述是「用起来像文档一样简单，能力上像图数据库一样强大」。它的核心不是文件夹层级，而是**每一段（block）都可以被链接与引用**，且链接天然双向。

## 在本知识库中的角色

它是历史链条上**最近的一环之前**：Bush 1945 → Nelson 1965 → 万维网 1989/1999 → **Roam 2017/2019** → [[obsidian]] 2020 → [[llm-wiki-pattern]]。

**它的历史意义在于「证明了需求存在」。** [[2026-09-18-appleton-bidirectional-links]] 的观察很直接：双向链接「不新」，是 Roam 的兴起让它「又火了一阵」。也就是说，**双向链接在个人笔记场景的需求一直存在，只是在公开网络上被治理问题压制**（见 [[bidirectional-links]]）—— Roam 证明了在**单用户私有域**内这个需求可以被释放。

**与 [[obsidian]] 的关系**：Roam 是托管服务且价格较高，Obsidian 用「本地 Markdown 文件 + 免费」接住了同一批需求，并因此成为 [[llm-wiki-pattern]] 里被推荐的「wiki 的 IDE」。**本库选择 Obsidian 而非 Roam，原因与 [[plain-text-and-git]] 一致：本地纯文本才能被 LLM 与 git 直接操作。**

**与 [[zettelkasten]] 的关系**：Roam 的流行与 Sönke Ahrens 2017 年《How to Take Smart Notes》的流行是同一波浪潮的两面 —— 一本把卢曼方法系统化的书，加上一款让方法可执行（且带双向链接）的工具。两者共同把「卡片盒」从学术史变成了消费级方法论。
