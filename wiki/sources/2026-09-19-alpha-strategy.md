## 关键要点

1. **讲稿给出的工具叫「Alpha（阿尔法）意识」**：金融学里 Beta = 对市场共同风险的暴露（搭顺风车），
   Alpha = 扣除市场因素后的风险调整后超额收益（行 49）。讲稿把它借用为「超出市场共识的那部分」，
   主张**只有 Alpha 才能积累经济租**。
2. **Beta / Alpha 的借用**：Beta 是搭市场顺风车的收益，Alpha 是「靠更高一层的认知、判断和动作硬生生多拿到的那部分」。
   「Beta 只能让你在市场中存活，只有 Alpha 才能给你积累经济租。」
3. **经济学史：从「不信 Alpha」到「错配」**（行 59–71）：新古典假设完全信息 / 完全理性 → 均衡 → 无超额利润；
   1968 年哈耶克「竞争是一个发现程序」→ 柯兹纳「企业家发现 / 警觉性」→ 世界充满「错配（Mismatch）」。
4. **波特 1996：运营效益 vs 战略定位**：运营效益 = 把同样的事做得更好（可被学会）；
   战略定位 = 换一套打法（不可模仿）。**战略定位必须伴随痛苦的「取舍（Trade-offs）」**。
5. **三本账**：现金账（今天）/ 能力账（明天）/ 位置账（后天）；「利润是今天的结果，能力是明天的原因，位置是后天的统治」。
6. **案例对比是讲稿最硬的说服结构**：柯达 / ASML、Kmart-Sears / 英伟达、诺基亚 / Airbnb —— 守租者衰、造 Alpha 者立。
7. **五步心法**：错配 / 认知 / 执行 / 占有 / 重构。讲稿自陈第二步（「凭什么由你来纠正」）最关键。
8. **两条库内接点 + 素材质量**：它回指本课两条既有线 ——「探索与利用」回指模块一 020 讲（见 [[explore-exploit-tradeoff]]）；「互补性资产」回指上一讲（见 [[2026-09-19-economic-rent]]）。**本份也是本库目前最干净的课程素材之一**：全篇为得到讲稿、**未发现 AI 加工段**，具名引注（哈耶克 1968 / 柯兹纳 / 波特 1996 / Alpha-Beta）经外核**逐条属实**。
