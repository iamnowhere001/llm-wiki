# 激励相容：好的制度不应该指望人「畏威怀德」（讲次表编号（推定）072）

> 一份 **225 行**的得到课程讲稿，**「模块五 参与者」第四讲**（071 是问答）。
> **纯讲稿，无 AI 加工段**（正文部分）。
>
> **核心命题**：现代世界既不是靠儒家（教化，让人「怀德」）也不是靠法家（赏罚，让人「畏威」）运行的，
> 而是靠**激励相容（Incentive Compatibility）** ——
> 「好的制度既不应该要求人是好人，也不应该像对待坏人一样去控制人 —— 而应该让*普通人*，在追求*自身*利益的同时，
> 顺手就能完成制度想要的事情」（行 54）。**制度的最高境界不是战胜人性，而是让人性为秩序打工**（行 56）。
>
> 全讲分四段推进：① 机制设计是经济学的**工程化**（行 62–66）；② 用销售提成改革说明它与儒法两家的**操作差别**（行 76–94）；
> ③ 一个激励相容的工厂制度 = **威、利、信、德**（行 112–136）；④ **强激励 / 弱激励**的分界与「显示原理」（行 156–182）。

## 关键要点

1. **激励相容的定义与来历**：「激励相容这个词，最早是波兰裔美国经济学家列奥尼德·赫维茨（Leonid Hurwicz）在 1972 年系统提出来的」（行 60），他因机制设计获 2007 年诺贝尔经济学奖（注 \[1\]）。
2. **正问题 vs 逆问题**（行 62）：传统经济学问「给定规则，人会怎么玩」；机制设计问「我想要这个结果，你能不能反推一套规则，让大家**自愿**玩出这个结果」。**机制设计是经济学的工程化**（行 64）。
3. **它与儒法两家的维度差**（行 68）：儒家依赖被统治者的素质，法家依赖统治者自己，「其实都不是根本办法」；激励相容承认「每个人都有自己的小算盘」，「但我不在乎」（行 70）。
4. **操作差别的标准范例**（行 76–94）：销售虚假承诺问题 —— 儒家开价值观工作坊、法家扣奖金，**激励相容则改提成结构**（分阶段发放 + 承诺不符则追回，行 84）。
   **判据句**：「法家是在行为之后处理人；激励相容是在行为之前设计局」（行 90）；「法家问：怎样让人不敢坏？激励相容问：怎样让坏不再划算，让好不再吃亏？」（行 92–94）
5. **非洲工厂的两个错误**（行 98–108）：① 把「条件好」当成激励到位 —— **参与约束 ≠ 激励约束**（行 102）；② 打骂管理不是有效的激励约束（行 106）。
6. **威、利、信、德**（行 112–136）：威 = **规则一定兑现**（不是棍棒，行 114–116）；利 = 可测任务让努力尽快变成钱（拉齐尔的计件工资研究，**生产率 +44%**，行 120）；信 = **承诺可信**（信不足时工资要短周期甚至日结，行 122–128）；德 = **身份生成**（晋升阶梯 + 小队制，行 130–136）。
   **关键限定**：「这些属性是对*制度*的要求，而不是对员工人品、也不是对管理者心力的要求」（行 136）。
7. **强激励 / 弱激励的分界**（行 156–170）：**算法性任务**（结果单一、易测）适合强激励；**启发性任务**（多维度、靠判断与协作，如科学家 / 官员 / 医生）用强激励反而不好（注 \[8\]）。「指标越可靠，奖金可以越直接；指标越粗糙，文化和声誉越重要」（行 170）。
8. **显示原理**（行 176–180）：迈尔森等人 1979 年证明（注 \[10\]）—— 任何复杂机制达成的结果，都存在一个等价的「直接机制」，让**说真话成为每个人的最优策略**。

## 摘要

**① 引子：非洲工厂（行 40–56）** —— 中国老板的「讲平等讲尊重」失败、改用凶狠监工反而走上正轨（行 40–44）。行 46 提出「畏威而不怀德」的问题。行 48–52 引出儒家 / 法家 / 第三种东西。

**② 机制设计（行 58–72）** —— 赫维茨（行 60）、正 / 逆问题（行 62）、工程化（行 64）、激励相容是「机制设计的灵魂」（行 66）。

**③ 销售提成的例子（行 74–94）** —— 三种方案的对照（行 78 / 80 / 82–84）。行 88「儒家要人做君子，法家威胁人别做小人。激励相容，则是让人做一个聪明的普通人」。

**④ 回到非洲工厂（行 96–108）** —— 两个错误（行 100–102 / 106–108）。行 104 引波拉德（注 \[3\]）：现代工人是被制度训练出来的。

**⑤ 威、利、信、德（行 110–136）** —— 四步（行 114 / 118 / 122 / 130）。含拉齐尔 +44%（注 \[4\]，行 120）、Kaur / Kremer / Mullainathan 的自控研究（注 \[5\]，行 126）、Hamilton 等的团队激励（注 \[6\]，**+14%**，行 134）、Bandiera 等的团队激励实验（注 \[7\]，行 134）。

**⑥ 思想史（行 138–152）** —— 行 142 引《道德经》《论语》；行 146 引**休谟 1741**「应当假定每个人都是无赖」；行 148 引**麦迪逊《联邦党人文集》第 51 篇**「如果人人都是天使，就不需要政府了」「必须用野心来对抗野心」。

**⑦ 强激励与弱激励（行 154–170）** —— 算法性 / 启发性任务的二分（行 160）；行 162 明确把**古德哈特定律**与「多任务委托代理问题」**挂账到后面的讲次**（「咱们后面再详细讲」）；行 164 引**自我决定理论**。

**⑧ 显示原理与收尾（行 172–188）** —— 行 176–180 显示原理；行 186 引**邓小平 1980 年**《党和国家领导制度的改革》（注 \[9\]）。
