## TL;DR

**本讲的思维工具是「凯利公式（Kelly criterion）」**：它解决的不是「怎么赢」，而是「**怎么一直赢**」（行 71）——
在一个**可重复、乘法式结算**的世界里，把「胜率 p 与赔率 b」翻译成「这一把该押多少」。
讲稿由此推出三条底线：**别清零、认知先行、追求复利**（行 135–145），
并把「勇敢」重新定义为**对本能的克服**（行 205）、把「自由」重新定义为**「你始终有下一次下注的能力」**（行 207）。

## 关键要点

1. **凯利公式来自 1956 年贝尔实验室的通信问题**（行 49）：约翰·凯利（John L. Kelly Jr., 1923–1965）
   设想一个赌徒通过**有噪声的私人电话线**接收赛马内幕（行 53–55），
   推出「长期复合增长率最大化」的最优下注比例，且**其增益对应这条信道的信息传输率**（行 59）。
2. **公式与算式**（行 75–85）：`f* = (bp − q) / b`；例：`p = 0.6, b = 1` → **押 20%**（算术正确）。
3. **赌场口诀「Kelly = Edge / Odds」**（行 89–91）：分母是市场给的赔率，分子 `edge = bp − q` 才是你的认知优势（行 97）。
   **「你比大众高明多少，凯利就能帮你赚到多少，但不能更多。」**（行 101）
4. **曹操评袁绍是本讲的负例**（行 41、107–111）：建安五年许都空虚、田丰献策，袁绍因幼子病不出兵，
   讲稿判为「**干大事而惜身**」——「如果 edge 好，出手是一种义务」（行 115）。
5. **生物学例证：表型赌注对冲（Phenotypic Bet-Hedging）**（行 123–129）：沙门氏菌、枯草芽孢杆菌让一部分个体休眠，
   **休眠比例在数学上等价于凯利公式的「未下注比例」**。
6. **三个底层指引**（行 135–145）：**别把自己清零**（贝叶斯主义者不假设 p = 1，还要留估计误差的余地）、
   **认知先行**（先问 edge 再想注码，「我们不是用认知去解释变现」）、**追求复利**（是系统，不是赌一局）。
7. **落到三个生活场景**（行 155–193）：职业规划（乘法资产 + 半凯利试水）、精力与健康（把日常活动当注）、
   **人际信任**（小仓位试探 → 逐步加仓 → 永远保留止损）。
8. **注释段只有 `[2]` 和 `[3]` 两条，且正文里看不到任何编号锚点**（行 213–215）——
   正文首条具名引注（凯利 1956）**没有 `[1]` 注释**。见核查表第 10 条。
9. **本份是本批四份里证据质量最好的一份**：讲稿段全部具名 / 可核主张**逐条对上**（凯利论文、年份、生平、公式、注释数学、细菌 bet-hedging）。

## 讲稿段摘要（C 段，行 35–209）

**① 开场：问题不是信息，是仓位（行 35–45）**
行 37：「凯利公式解决的问题，则是**面对有价值的信息时，你的行动与之不匹配**。」
行 39 的对撞：为了几毛钱波动加杠杆杀进杀出，却在真正的赛道上犹豫不决 ——「**押太大和不敢押都是错的。这不是信息问题，这是仓位问题。**」（行 43）

**② 凯利其人与其题（行 49–59）**
行 49：「约翰·凯利（John L. Kelly Jr., 1923–1965）是贝尔实验室的科学家，他 1956 年那篇著名的论文，原本研究的是通信问题。」
行 51 交代与香农的关系：香农已证明可扩大信道降低错误率，但**不能绝对消除错误**。
行 59 给出结论：最优下注比例 f\* 「在数学上竟然完全等同于这条电话线的'信息传输率'」。

**③ 公式（行 73–85）**：行 75 为公式配图（`img-01`）；行 85 的例：`p = 0.6, b = 1 → 20%`。

**④ 口诀与 edge（行 89–103）**
行 91 为口诀配图（`img-02`）；行 97：「真正应该让你动心的是分子，edge……**Edge 是你的认知优势！**」
行 103：「如果你不掌握大于零的 edge，凯利就要求你不要下注。说白了就是**你要是不比别人高明就别玩**。」

**⑤ 袁绍之失（行 107–113）**
行 107：「建安五年，曹操去讨伐刘备，大本营许都空虚，袁绍面临一个绝佳的战略窗口。」谋士田丰建议出兵。
行 109–111：袁绍因幼子病重不出兵 → 曹操回兵 → 官渡之战袁绍全军覆没。

**⑥ 生物学例证（行 121–129）**
行 123：单细胞生物的「**表型赌注对冲（Phenotypic Bet-Hedging）**」。
行 125：沙门氏菌（Salmonella）与枯草芽孢杆菌（Bacillus subtilis）会让一部分个体休眠。
行 127：「**进入休眠状态的细胞比例，在数学上等价于凯利公式中的未下注比例。**」

**⑦ 三条指引（行 133–145）**
行 137：别把自己清零（`p` 不等于 1 + 估计误差 → 还要多留余地）。
行 141：认知先行（「**我们是把认知变现，不是用认知去解释变现。**」+ 巴菲特不买看不懂的股票）。
行 145：追求复利（「这是一个系统，而不是只赌一局」）。

**⑧ 三个场景（行 155–193）**：职业（乘法资产 / 半凯利 / 分数凯利）｜精力与健康（日常活动即下注）｜
**信任（小仓位试探 → 逐步加仓 → 止损机制）** —— 行 187 的理由句：「为什么不应该把银行密码告诉别人？因为**潜在收益非常小，潜在损失非常大**」。

**⑨ 收束（行 197–209）**
行 199：「**你有多大 edge 谈多大变现。**」行 205：勇敢是「对本能的克服」。
行 207：「人生的根本自由是**你始终有下一次下注的能力**。」
行 209：「世界既不会奖励你的努力，也不会惩罚你的动机。**它只结算你的概率质量。**」

**⑩ 注释（行 211–215）**
行 213 `[2]`：「这里我们采用了流行的解读，但其实我把公式改写成 `f* = p - q/b`，赔率的作用就很直观了。」
