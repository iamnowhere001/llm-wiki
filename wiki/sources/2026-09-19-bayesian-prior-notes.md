## TL;DR

**讲稿用贝叶斯公式把「主观判断」从道德审判的领域搬到认知工程的领域。**
工具是三个动作：**设定先验 → 用证据更新 → 永不给先验设 0 或 1（克伦威尔法则）**。
本讲**显式回指「自由能原理」**，并补上该框架的另一半 —— **主动推断**（改变环境而不是改变模型）。

## 讲稿段摘要（C 段，行 35–167 + 注释 171–175）

**① 开场：把前三讲串起来（行 35–43）**
行 35 三个日常情境（新同事 / 爆料 / 身体不舒服）；行 37「**设定价值函数、选择概率分布、使用一定
颗粒度的模型，其实都是在做主观的选择。**」—— **显式回指本模块前三讲**；行 39「如果你认同这些，
你可能是一个『贝叶斯主义者』」；行 41 先验的定义（单数 / 复数、事件概率 / 领域观念 / 整个世界观）；
行 43「**先验就是你的成见。但成见是认知的起点。而且这个起点是可以被量化、可以被更新，也可以被审计的。**」

**② 贝叶斯公式（行 47–65）**
行 51–63 P(H)、P(H|E)、P(E)、P(E|H) 四项逐一定义（先验概率 / 后验概率 / 总概率 / **似然度**）；
行 65「**后验 = 先验 + 证据更新**」（取对数后乘法变加法）。

**③ 罕见病算例（行 67–79）**
行 67 发病率 **0.1%**、灵敏度 **99%**、误报率 **1%**；行 69 **笨办法** —— 1000 人体检，真阳性 ≈ 1、
假阳性 ≈ 10、总阳性 11 → P(E) = 11/1000；行 71 **P(H|E) = 1/11**；行 75「**如果先验原本很低，
哪怕证据很强……你的后验概率也还是不高。**」；行 77 两个类比（足球天才 / 鬼故事）。

**④ 频率主义 vs 贝叶斯主义（行 83–97）**
行 83 贝叶斯是 18 世纪人物，**「他在 1740 年代推导出了这个公式」**；「成为一个范式，则大约发生在
**1920-1930 年代**」（← 核查表第 4、5 条）；行 85「当你说『概率』的时候，你到底是在描述**世界**，
还是在描述**自己对世界的信心**？」；行 87 **频率主义**（概率是客观属性、有「真值」）；
行 91 **贝叶斯主义**（概率是**信念的度量**）；行 93「频率主义者是世界的**旁观者**，而贝叶斯主义者
则是世界的**参与者**」。

**⑤ 两个应用：垃圾邮件与 LLM（行 101–123）**
行 101「把这个事儿已知的频率、或者说世人普遍的信念或者科学知识，当成你的先验，作为出发点」；
行 107–115 垃圾邮件过滤（先验 20% + 逐词更新）→ 行 115「程序不是在瞎猜，而是在**记账**」；
行 117「现在的 AI 大语言模型（LLM），其实就是一个**巨型的贝叶斯预测机**」；行 119「你给模型一段
提示词（Prompt），你就是在给它输入观测证据，**强迫它更新后验概率**」；行 121「AI 公司会设法给模型
一个**不可轻易被提示词推翻的先验**……这就是「**对齐（Alignment）**」」。

**⑥ 接入自由能原理（行 127–135）**
行 127「联系「**自由能原理**」，我们可以说人的大脑就是一台主动预测的贝叶斯推理机」；行 129 拿杯子
喝水的先验 / 惊奇 / 更新；行 133「**除了更新先验（也就是知觉推断），你还有另一个选项，那就是主动推断：
你可以改变环境，让环境适应你的先验。**」（← **本讲对 [[free-energy-principle]] 最直接的补充**）；
行 135 **凯恩斯**（John Keynes）名言（← 核查表第 3 条）。

**⑦ 两种错误与克伦威尔法则（行 141–155）**
行 143–147 **第一种错误「完全没有先验」**（听风就是雨）→「那谁还敢指望你呢？」；
行 149–155 **第二种错误「先验不可动摇」**（把概率设成 0 或 1）；行 151 **克伦威尔法则（Cromwell's Rule）**，
典故出自 **1650 年克伦威尔致苏格兰教会的信**：「我恳求你们，在基督的慈悲下，想一想你们可能错了」；
行 155「哪怕你特别特别相信一个事情，你总可以把它的先验概率设成 **99.999%**，但是不要设成 1」。

**⑧ 收束与注释（行 159–175）**

行 161：新同事值不值得信任（环境先验 + 办事更新）。
行 163：「传统智慧有时候说『人性本善』，有时候又说『防人之心不可无』……**放在贝叶斯公式的框架下看，
