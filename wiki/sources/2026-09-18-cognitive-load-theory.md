# 认知负荷理论：因为文具多，所以是差生

## 关键要点

1. **学习不是硬件问题，是带宽问题** —— 长期记忆近乎无限，瓶颈在工作记忆（4–7 个元素）。
2. **秘鲁「每个孩子一台笔记本电脑」的十年 RCT**：2025 年揭晓，发电脑对学业成绩**无显著正面影响**，
   按时升年级比例反而**平均下降一个百分点**。
3. **三种认知负荷**：内在 / 外在 / 增益；较新认识（含斯韦勒 2023）认为**增益不必单列**。
4. **图式 = 压缩包** —— 差生与优等生的差别不在脑子快慢，在压缩包多少。
5. **有效教学四心法**：管理内在负荷 / 直接教学（范例学习 + 指导淡出）/ 消除外在负荷 / 差异化教学。
6. **AI 当导师 ≠ 当代写神器** —— 外包增益负荷则图式不形成，成绩下降。

## 归属判断

**填的是 [[peak-performance]] 的「学习力」缺口** —— 该项目 `goal` 含「动机 / 学习力 / 创造力 / 心流」四项，
本讲是**学习力**一侧。

**但它没有换材料类型。** 按该项目已确立的判据（**判据是「材料类型不同」，不是「作者不同」**），
本讲与 Kotler / Storoni / Grant / 迪昂 那批**同属「通俗转述」** ——
万维钢是科普作者，不是一手研究者（对比 [[john-dunlosky]]：文献本体入库）。

**本讲的独特价值在别处**：它给本库带来**第一个带年份与规模的可核查引注簇**
（斯韦勒 1980s/2023、2025 荟萃分析、十年 RCT）。**这使本库第一次可以对通俗素材做
「按图索骥」的一手核查** —— 此前那批素材连「图」都没有。
