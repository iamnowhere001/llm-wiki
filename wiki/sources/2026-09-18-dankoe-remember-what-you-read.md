# How to remember everything you read (stop trying) — Dan Koe

> 一篇创作者视角的长文，论证「记不住读过的东西不是问题，不理解才是」。提出学习是**输出过程**而非输入过程，并把「第二大脑」重新定义为**创作燃料库**（共同笔记簿）。

## 关键要点

1. **记住 ≠ 理解。** 想把读过的都记住，动机往往是「想显得聪明」—— 一个无意识的身份符号。而显得聪明来自理解，不来自记忆。
2. **学习是控制论过程。** 目标 → 感知 → 比较（误差信号）→ 行动。四要素缺一不可，而大多数人卡在「没有目标，因此没有误差信号」。
3. **学习是输出过程，不是输入过程。** 因为输出倒逼输入。链条是：**目标 → 误差信号 → 过滤器 → 相关性 → 留存**。没有目标，大脑不会标记什么重要。
4. **不要「开始学习」，要「开始一个项目」。** 任何不直接推进项目的东西都不值得现在学 —— 反正也记不住。
5. **「第二大脑」不是没用，是被误用。** 书签和笔记存了再也没看过，等于把时间浪费在「感觉自己学到了」上。
6. **正解是共同笔记簿（commonplace book）。** Marcus Aurelius 的《沉思录》、达芬奇的笔记本都是这一类。与普通人的关键差别：**他们的笔记是创作的燃料**，不是收藏品。Seneca 的比喻：采百花之粉，酿自己的蜜。
7. **落地三步**：选对工具（或自建 AI 系统）→ 只采集「最能代表你理想心智」的想法 → 通过创作闭环让知识生效。
8. **自建方案就是 Claude Code + Obsidian**：让 Claude 建两个 skill —— 「保存想法」与「处理收件箱」（打标签、归位、**加反向链接**）。

## 摘要

文章分两大块。

**第一块：如何真正学会任何东西。** 作者用控制论（cybernetics，源自希腊语 *kybernētēs*，掌舵人）解释学习：掌舵人不是指一次方向就完事，而是持续读取当前状态（风、浪、航向）、与目标航向比较、然后修正。这就是试错。四要素是参考信号（目标）、传感器（感知）、比较器（差距＝误差信号）、执行器（行为）。

关键推论：**学习是输出过程**。目标产生误差信号 → 误差信号产生过滤器 → 过滤器产生相关性 → 相关性产生留存。作者举了两个具体例子：学 After Effects 不该看通用教程，而该带着一个具体项目去找「最接近我想做的东西」的那一个教程，只取用得上的一小段技术，然后重复；学吉他不该先学乐理，而该选一首想弹的歌，一个和弦一个和弦地啃。

**第二块：第二潜意识。** 作者自述用过所有笔记系统（从 Roam Research 开始），甚至做过 Kortex（后来演变成 Eden）。他的立场不是「第二大脑没用」，而是**「被误用了」**。

他给出的诊断是：普通人的笔记和书签**再也不会被看见**。而历史上那些真正有共同笔记簿的人（Marcus Aurelius、达芬奇、马克·吐温、爱默生式的引文传统……）有一个共同点 —— 他们的笔记是**创作的燃料**。

因此他给出三步法，其中 Step 1 的关键是「让想法不会消失在虚空里」—— 因为创作依赖你**重新浮现**它们的能力。他给出两条路：Claude Code + Obsidian（自建），或 MyMind / Eden（托管，自动打标签、分类、嵌入）。

## 与现有知识库的关系

**这是本知识库目前最重要的一个交叉点。** 它同时提供了三样东西：

1. **一个独立收敛的证据。** 作者在完全不同的领域（写作/创作）独立得出了与 [[llm-wiki-pattern]] 几乎相同的架构 —— 包括让 LLM 做归档、打标签、加反向链接。详见 [[commonplace-book-vs-llm-wiki]]。
2. **一个理论机制。** [[cybernetic-learning]] 解释了**为什么**知识库需要目标驱动 —— 这是原 Gist 没有回答的问题。
3. **一个反例式的批评。** 他直接批评了「Claude skills 是一阵会退去的风潮」，这构成对 [[second-brain-skill]] 路线的第三方质疑。

**与 [[use-cases]] 的关系**：这篇文章本身就是「创作者 / 写作者」场景的一手材料，可以补进那张场景表。

**与 [[index-and-log]] 的关系**：他主张嵌入检索（「什么在附近」）优于关键词检索（「什么相关」），并列出自己维护向量库的隐性成本 —— 这是「索引文件何时失效」这个问题的另一条证据链。
