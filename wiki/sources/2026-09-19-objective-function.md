## 讲稿段摘要（C 段，行 36–230）

**① 破题：地球 Online 的后台（行 38–48）**
行 38 用「地球 Online」立喻（「你终于黑进了这个游戏的后台，你调出了源代码」）；行 42 试举三种可能的奖励函数
（积德行善 / 自我利益最大化 / 修仙式的吸收灵力）；行 44 想看排行榜（「这台服务器已经跑了四十亿年」）；
行 46 给结论：「**这个游戏没有明确的「奖励函数」，而且也没有排行榜**」；行 48 给理由 —— 我们设计过自己的游戏
（写过奖励函数、训练过智能体、设计过考试和 KPI），并**显式回指「我们讲过「古德哈特定律」」**。

**② 工具理性 / 价值理性与休谟断头台（行 52–64）**
行 52 立题：「奖励函数决定我们\*应该\*做什么」；行 54 署名韦伯 —— 科学技术与思维工具教的是\*怎么\*做事，
即「**工具理性**」（手段最有效地达成既定目标）；行 56 给对偶「**价值理性**」；
行 58 引**大卫·休谟 1740 年《人性论》**的「**休谟断头台**」：**只靠「实然」推不出「应然」**（is–ought gap）；
行 60–62 用「外面在下雨 ≠ 你应该带伞」（中间藏着「你不喜欢淋雨」这个价值前提）说明缺口；
行 64 引休谟「**理性不过是激情的奴隶**」。

**③ 博斯特罗姆：正交性论题（行 68–72）**
行 68 署名：**牛津大学哲学家尼克·博斯特罗姆 2012 年**提出「**正交性论题（orthogonality thesis）**」——
智能水平与最终目标是两根互相垂直、彼此不决定的轴；并提**「回形针问题」**（能力无穷的超级智能可以一心一意做回形针）；
行 72 收：「我们跟 AI 最大的区别，似乎就是，**我们得自己找目标**」。

**④ 「应该做什么」确实是问题（行 74–82）**
行 74 承认现实反驳（多数人每天为生计奔忙、传统道德与宗教一直在给答案）；行 76–78 反问「到底哪个是对的？」；
行 82 断：「**没有任何证据表明宇宙中存在一个颁奖系统**……而且你也没地方兑奖」。

**⑤ 造物主视角：假设有奖励函数会怎样（行 84–98）**
行 84–86 用「造物主视角」立论，并**主动划界**：「注意这不是一个「应然」……**这是一个「实然」**：我们观察到的这个宇宙，
本来就是已经存在了很久，而且是多姿多彩的」；行 88 假设有奖励函数；行 90 引出**「摩洛克」**（「咱们课程讲过那个局面」）；
行 92 用修仙小说 / 网络游戏论证「杀人夺宝就是最优策略」→ 世界成为「**被榨干的矿场**」；
行 96 给**趋同机制**：「不管你那个奖励函数是什么……竞争之下，早晚所有人都会变成同一个样子」；
行 98 收「连观众都没有」。

**⑥ 不稳定 + 细菌持留（行 106–120）**
行 106 转「更可怕的是，那样的世界会非常不稳定」；行 108 **显式回指「适应性循环」**：「优化就会导致过拟合，
过拟合就会导致不稳定」；行 110 立句「**多样性不是为了好看，多样性是最重要的生存策略**」；
行 112 **显式回指「凯利公式」**并给生物学例证：细菌种群里极少数细胞会自发切换到长得极慢的
「**持留态（persister state）**」—— 现象叫「**细菌持留性（bacterial persistence）**」，细胞叫**持留菌（persister cells）**；
行 114 给机制「**你越努力生长，你越是靶子**」（许多常用抗生素瞄准的正是细胞壁合成、DNA 复制这类「正在干活」的环节）；
行 116 说「研究者把这种现象称为「**保险单**」」，并给「**最优的切换速率主要取决于环境多久变一次**」；
行 120 收「**因为你读不到下一道题，所以你必须留一批人去做现在看起来没用的事**」。

**⑦ 「没给奖励，但给了约束」（行 126–148）**
行 126 承上（越了解因果越难相信有奖励函数）；行 128 转出「**确实没给奖励，但是给了约束**」；
行 136 给清单：**物理规律、可行边界、生物淘汰机制**，即「硬约束」—— 「天地不仁以万物为刍狗，**它不颁奖，但是它会清场**」；
行 138–140 借**塞林格《麦田里的守望者》**意象（麦田 + 悬崖，且「到处都是悬崖和陷阱」）；
行 142–144 是全讲最锋利的一步：**能落脚的地方已经很窄 → 你只能沿剩下的一条条窄地走 → 明明是\*只能\*，
可因为那些窄地像路一样，你感觉你就\*应该\*沿着这些路走**；行 148 收
「**一个只会删除的机制，运行了四十亿年之后，从统计上看，它很像一个奖励函数**」。

**⑧ 工具性收敛：活、繁衍、合作（行 152–170）**
行 152 再引博斯特罗姆，署名「**工具性收敛（instrumental convergence）**」—— 最终目标千奇百怪，但中间手段会收敛到
同一批（保住自己、保住目标不被改写、增强能力、获取资源）；行 154–160 论证「**「想活下去」不是一个奖励，
也不是一种价值观，而是一个约束**」；行 162 补繁衍（「你繁衍的不一定是基因，也可以是文化，是手艺，是制度」）；
行 164 补合作；行 166 给实证：**2019 年牛津大学的三位人类学家**翻 60 个社会的民族志，
检验**七条合作规则**（帮助家人 / 帮助自己所属的群体 / 有恩报恩 / 勇敢 / 尊重上位者 / 公平分配 / 尊重他人的财物），
**七条在所有社会里的评价一律正面**；行 168「这不是文化上的巧合，这也是约束」。

**⑨ 时间视界 → 意义（行 174–186）**
行 174–176 从「活下去 / 繁衍 / 合作」推出必须**拉长「时间视界（time horizon）」**；
行 178 给三尺度（个体：延迟满足 / 复利 / 声誉；组织：五年才见效的投入 vs 只盯季度报表；文明：盖一百多年的建筑）；
行 180「「意义」就这样出来了」；行 182 给实证：**2013 年几位美国社会心理学家**用问卷调查发现
「幸福」= 当下的、索取的、需求被满足的，「意义」= 跨时间的、给予的、连接过去与未来的；
行 184 给全讲最好记的一例：**「半夜起来给孩子换尿布会拉低你当期的幸福感，却会明显提升你的意义感」**；
行 186 收「你心里那个叫「意义」的感受器，量的根本不是快乐，而是你的时间视界有多长」。

**⑩ 美德 = 对约束的适应（行 190–204）**
行 190 推出一串「更熟悉的词」（节制 / 审慎 / 勤勉 / 耐心 / 守信 / 公平 / 互惠 / 勇敢 / 忠诚 / 照料弱者）；
行 194 断：「很多人以为美德是奖励函数……**可我们前面的推导表明，这些只不过是对约束条件的适应而已**」；
行 196–198 处理反驳（行善后心里舒服 ≠ 宇宙发奖），答：「那是**演化在你身上装的仪表盘**」；
行 200 列仪表（糖是甜的、性是愉快的、被接纳是舒服……）；行 204 再申「这一切无非是我们对宇宙硬约束的适应」。

**⑪ 自由 = 空白区（行 208–216）**
行 208「你可以尊重一切约束，践行一切美德，但是……**你还是得自己给自己设定目标函数**」；
行 210「这恰恰就是**自由的来源**」；行 212 给三个例子（研究一只甲虫的翅膀 / 投入一个没有实用价值的定理 /
爱一个从任何角度算都不划算的人）；行 214 给**功能理由**：「正是那些「无用」的好奇、「不划算」的美感、
「不理性」的忠诚，让这个世界不至于过度拟合眼前那个唯一的答案，也为下一次变化保留了别的解法」；
